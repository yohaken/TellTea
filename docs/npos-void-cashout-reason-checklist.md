# nPos — กรอกเหตุผลทำลายบิล + เงินออก

อัปเดต: **1.14.82** · vc **105** · `APP_BUILD` 409 · `POS_BUILD` 134

## ปัญหา
1. **ทำลายบิล** — มีช่องเหตุผลแต่พิมพ์ไม่ได้ (ไดอะล็อก scale ทับ EditText / ไม่โชว์คีย์บอร์ด)
2. **ถอนเงินกลางกะ (เงินออก)** — ไม่มีช่องเหตุผลเลย

## แก้แล้ว
| จุด | พฤติกรรม |
|-----|----------|
| `NposConfirmDialog` | มี EditText → **ไม่ scale** · เปิด soft keyboard · focus ช่องพิมพ์ |
| ทำลายบิล | ช่องเหตุผลหลายบรรทัด · **บังคับกรอก** |
| ยกเลิกบิลรอส่ง | ถามเหตุผลเช่นกัน |
| ถอนเงินกลางกะ | ช่องเหตุผล · **บังคับกรอก** · เก็บใน `cashDropNotes` · โชว์บนแผงกะ · ส่งตอนปิดรอบ |

## คนเทส
1. รายการบิล → ทำลาย → พิมพ์เหตุผลได้ · ว่างแล้วกดไม่ได้
2. กะ → ถอนเงินกลางกะ → กรอกจำนวน + เหตุผล → แผงกะขึ้นรายการเหตุผล
3. ปิดกะแล้วเหตุผลอยู่ใน sync (`cashDropNotes`)

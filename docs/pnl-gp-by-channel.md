# หัก GP รายช่องทาง → VAT + P&L (ยอดโอนจริง)

> หน้า `/vat-sales/` บล็อก **2) GP รายช่องทาง** (ระหว่างภาษีขายกับภาษีซื้อ)  
> อัปเดต 2026-07-29

---

## สูตร (ของจริง — ไม่ประมาณก้อน)

```
รายได้ช่องทาง (จากตารางขาย)
− ยอดโอนหลัง (ใส่เองจากสลิป/แพลตฟอร์ม)
= คชจ. GP                    → รวม Σ → หักรายได้ P&L
เรท % = คชจ. ÷ รายได้ × 100

ภาษีซื้อ GP (ต่อช่องทาง):
  โหมดรายได้รวม VAT  → คชจ. × 7/107
  โหมดรายได้ก่อน VAT → คชจ. × 7/100
  หรือใส่จากใบกำกับ (override)
Σ ภาษีซื้อ GP เดลิเวอรี่ → แถวภาษีซื้อเดลิเวอรี่ (ปิดประมาณก้อน)
```

แยก ShopeeFood / Grab / LINE MAN / หน้าร้าน  
**ห้าม** ใช้ประมาณก้อน `gpOfOutput≈⅓` เป็นฐานหลักของภาษีซื้อ GP  
เรทเฉลี่ยถ่วงน้ำหนัก = ภาพรวมเท่านั้น หลังมีตัวเลขจริงรายช่องทาง

---

## คอลัมน์ในตาราง

| คอลัมน์ | ใครใส่ | หมายเหตุ |
|--------|--------|----------|
| รายได้ | ระบบ | จากยอดขายแยกช่องทาง |
| **ยอดโอนหลัง** | คน | ใส่ของจริง |
| คชจ. GP | ระบบ | รายได้ − โอนหลัง → P&L |
| เรท % | ระบบ | คำนวณจากคชจ. |
| **ภาษีซื้อ GP** | ระบบ / คน | คำนวณจากคชจ. หรือใส่จากใบกำกับ → VAT |

เรท/ยอดโอน/`gpVatOverride` จำใน `meta/vatMonthlySettings.pnlGpByChannel` ใช้เดือนถัดไป

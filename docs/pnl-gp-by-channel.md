# หัก GP รายช่องทาง → P&L (ยอดโอนจริง)

> หน้า `/vat-sales/` แท็บปิด P&L · ตาราง「รายได้แยก → P&L」  
> อัปเดต 2026-07-29

---

## สูตร (ของจริง — ไม่ประมาณก้อน)

```
รายได้ช่องทาง (จากตารางขาย)
− ยอดโอนหลัง (ใส่เองจากสลิป/แพลตฟอร์ม)
= คชจ. GP
เรท % = คชจ. ÷ รายได้ × 100  (คำนวณให้)
```

แยก ShopeeFood / Grab / LINE MAN / หน้าร้าน  
**ห้าม** ใช้ประมาณก้อนจากภาษีซื้อ GP VAT มาแทนยอดโอนจริง

---

## คอลัมน์ในตาราง

| คอลัมน์ | ใครใส่ | หมายเหตุ |
|--------|--------|----------|
| รายได้ | ระบบ | จากยอดขายแยกช่องทาง |
| **ยอดโอนหลัง** | คน | ใส่ของจริง |
| คชจ. GP | ระบบ | รายได้ − โอนหลัง |
| เรท % | ระบบ | คำนวณจากคชจ. |

เรท/ยอดโอนที่ตั้งไว้จำใน `meta/vatMonthlySettings.pnlGpByChannel` ใช้เดือนถัดไป

# nPos — แผงรอบขาย + ช่วงชีพจรจากหลังร้าน

อัปเดต: **1.14.48** · `APP_BUILD` 306 · `POS_BUILD` 101 · vc **71**

## ทำไมตั้งวินาทีจากหลังร้าน

- ชีพจร/เช็คเวอร์ชันไม่ควรฝังตายใน APK — ระบบนิ่งแล้วอยากยืดเป็น 10–30–120 วิ โดยไม่ปล่อยเวอร์ชันใหม่
- ค่าอยู่ที่ `meta/pos.heartbeatIntervalSec` · แท็บเล็ตอ่านจาก heartbeat ทุกครั้ง · clamp **5–600** · ค่าเริ่ม **5**
- เช็ค APK ยัง throttle แยก (อย่างน้อย ~20s หรือ 4× ชีพจร) เพื่อไม่ยิง `latest.json` ถี่เกิน

## 2) หลักบัญชีที่ใช้ (ร้านเดลิเวอรี่ + หน้าร้าน + VAT)

ร้านนี้มี **สองสมุดความคิด** คนละงาน — ห้ามปนสูตร

### ก) ชั้นเงินสด / กำไรร้าน (ใช้คิดกำไร + ภ.ง.ด.)

| รายการ | ความหมาย | ที่มา |
|--------|----------|--------|
| **รายได้ถึงร้าน** | เงินที่ร้านได้รับจริง | เดลิเวอรี่ = **ยอดโอน** (หลังหัก GP แพลตฟอร์มแล้ว) · หน้าร้าน = เงินรับจริง (ไม่มีหักแพลตฯ) |
| **คชจ. GP** | ค่าคอมฯ ที่แพลตฯ หักก่อนโอน | โชว์ติดตาม + ใช้คิดภาษีซื้อ · **ไม่หักซ้ำในกำไร** (อยู่ในยอดโอนแล้ว) |
| **ภาษีซื้อ GP** | VAT บนบิลค่า GP | **ไม่ใช่เงินหักเพิ่มจากโอน** · ใช้ยื่น ภ.พ.30 |
| **คชจ. บช.** | COGS / SGA / อื่น จากสองสมุด | ledger + ownerBooks · **สินทรัพย์ไม่หักกำไร** |
| **กำไรเดือน** | รายได้ถึงร้าน − คชจ. บช. | ไปสรุปรับปี → ภ.ง.ด. |

```
รายได้ถึงร้าน = Σ ยอดโอน SF/GB/LM  +  ยอดหน้าร้าน     ← คอลัมน์โอนจากนำเข้า (ไม่ต้องคอลัมน์รายได้แยก)
คชจ.หักกำไร  = คชจ.บช.(ไม่รวมสินทรัพย์)              ← GP ไม่หักซ้ำ
กำไรเดือน     = รายได้ถึงร้าน − คชจ.หักกำไร
```

> รายได้ร้าน ≠ ยอดขายแพลตฟอร์ม  
> ยอดขายใช้คิด **ภาษีขาย** · ยอดโอนใช้คิด **กำไร** · GP≠ ใช้คิด **ภาษีซื้อ** เท่านั้น

### ข) ชั้น VAT / ภ.พ.30 (แยกกล่อง — ไม่หักออกจากกำไรด้านบน)

| รายการ | สูตร (default) | หมายเหตุ |
|--------|----------------|----------|
| **ยอดขาย** | เดลิเวอรี่ช่องทาง + หน้าร้าน (โอน/สด) | จากนำเข้า / กรอกเดือน |
| **ภาษีขาย** | ยอดนำส่ง × 7/107 | หน้าร้านอาจมี % นำส่ง (play-safe) แยกจากเดลิเวอรี่ที่ส่ง 100% |
| **ภาษีซื้อ** | VAT จากบิล GP + VAT จากบิลวัตถุดิบ/สองบช. | ปัดลง / claim factor ได้ |
| **VAT สุทธิ** | ภาษีขาย − ภาษีซื้อ | นำส่งสรรพากร · **ไม่เอามาหักกำไรเดือน** |

```
[ยอดขาย] → ภาษีขาย
[บิล GP + บิลบช.] → ภาษีซื้อ
ภาษีสุทธิ = ขาย − ซื้อ   ⟵ กล่อง VAT คนละชั้นกับกำไร
```

### ค) สิ่งที่ “หน้าร้าน” ต่างจากเดลิเวอรี่

| | เดลิเวอรี่ | หน้าร้าน |
|--|------------|----------|
| ยอดขาย | มี (คิดภาษีขาย) | มี (คิดภาษีขาย) |
| หักค่าแพลตฟอร์ม / GP | มี | **ไม่มี** |
| เงินถึงร้าน | ยอดโอน | = ยอดขาย (หรือยอดรับจริง) |
| ภาษีซื้อ GP | มี | ไม่มี |

### ง) สองสมุดในร้าน

- **ดึงเข้าคชจ.** → หมวด COGS / SGA / อื่น (กำไร)  
- **ดึงเข้าภาษีซื้อ** → เฉพาะรายการที่มี VAT + claim  
- สินทรัพย์โชว์ได้ แต่ไม่เข้าคชจ.สุทธิ

### จ) ล็อกเดือน

`filed` = ปิดงบ · ห้ามแก้ทุกช่อง (รวมยอดที่ซิงก์จากนำเข้า)

## 3) โครงหน้าใหม่ (เป้าหมาย UX)

หนึ่งหน้า · เลื่อนลงตามสมุด · แต่ละกล่อง **งานเดียว**

```
เลือกเดือน · สถานะ · รอบตัดยอด
────────────────────────────────
A) รายได้ถึงร้าน          ← ยอดโอน SF/GB/LM + หน้าร้าน
B) คชจ.                   ← GP เดลิเวอรี่ + ดึงสองบช.
C) กำไรเดือน + ภ.ง.ด.     ← A − B · ค่าลดหย่อน · สรุปปี
D) VAT (ภ.พ.30)           ← ยอดขาย→ภาษีขาย · ภาษีซื้อ · สุทธิ
────────────────────────────────
ร่าง / บันทึก / ปิดงบล็อก
```

- ทุกตัวเลขหลักมี **บรรทัดที่มา 1 บรรทัด** (เช่น `SF+GB+LM+หน้าร้าน`)  
- ไม่มีปุ่ม “ใช้ยอดคำนวณ” ที่ความหมายคลุมเครือ — รายได้สุทธิ = ผลรวมช่องด้านบนเสมอ (แก้ได้ทีละช่องทาง)  
- นำเข้า: ยังซิงก์เข้า A/B/D อัตโนมัติเหมือนเดิม · **ไม่แก้โค้ดนำเข้าในเฟสนี้**

## 5) เฟสงาน

> สถานะ 2026-07-29: **R0–R4 ลงโค้ดแล้วใน 4.442** · รายละเอียด UX ปรับทีหลังได้

### R0 — ล็อกหลักการ

**ส่งมอบ:** เอกสารนี้ + หลักการเริ่มต้น

- [x] รายได้ร้าน = ยอดโอน + หน้าร้าน (ไม่ใช่ยอดขาย)
- [x] หน้าร้านไม่มี GP
- [x] VAT แยกกล่อง ไม่หักกำไร
- [x] นำเข้าไม่รื้อ — แค่รับยอดเข้าหน้าใหม่

---

### R1 — โมเดลเดือนบาง + อะแดปเตอร์นำเข้า

**เป้า:** นิยาม `MonthBooksView` (ชื่อชั่วคราว) อ่านง่าย

```
income: { shopeeTransfer, grabTransfer, linemanTransfer, storefront, total }
costs:  { gpByChannel, booksOpex, total }   // ไม่รวมสินทรัพย์
vat:    { salesByChannel, outputVat, inputGpVat, inputBooksVat, netVat }
pit:    { monthProfit, allowance, year… }
status: draft | saved | filed
```

- อ่าน/เขียนผ่าน adapter ทับ `vatMonthlyReturns` เดิมได้ (migration น้อย)  
- รับ event จากนำเข้า → เติม `income.*Transfer` + `costs.gp*` + `vat.sales*`  
- สคริปต์เทสสูตรเงินสด / VAT แยกกัน

**เลิกพึ่ง** สะพาน `buildIncomeBridge` ก้อนใหญ่ใน UI (ย้ายเลขเข้าโมเดลใหม่)

---

### R2 — UI หน้าเดือนใหม่ (แทนของเดิม)

**เป้า:** คอมโพเนนต์ใหม่ เช่น `VatMonthBooks.tsx` สลับใน `page.tsx` แทน workbench เก่า

| กล่อง | เนื้อหา |
|-------|---------|
| A รายได้ | 4 ช่องโอน/ร้าน · รวม = รายได้สุทธิ (อ่านอย่างเดียวหรือ derive) |
| B คชจ. | GP ต่อช่องทาง · คชจ.บช.ผสานอัตโนมัติ · รวม |
| C กำไร+ภ.ง.ด. | กำไรเดือน · ลดหย่อน · ดึงปี · export |
| D VAT | ยอดขาย→ภาษีขาย · ภาษีซื้อ GP+บช. · สุทธิ |
| แถบปุ่ม | ร่าง · บันทึก · ปิดงบ / ปลดล็อก |

- ของเก่า `VatMonthlyWorkbench` คงไฟล์ไว้จนกว่า R2 นิ่ง แล้วค่อยถอด (R4)  
- ไม่มี local-draft ซ้อนซับซ้อนในรอบแรก — เซฟคลาวด์เป็นหลัก (หรือ draft เบา ๆ ทีหลัง)

### R3 — ผูกของจริงในร้าน

- ดึงสองบช. → คชจ. + ภาษีซื้อ (claim) เหมือนเดิมแต่ API ชัด  
- ปิดงบ → `monthlyIncome` / P&L  
- เดือนที่เคย `filed` ยังล็อก  
- เทสกับเดือนที่มีนำเข้าแล้ว 1 เดือน (ยอดโอนขึ้นกล่อง A เอง)

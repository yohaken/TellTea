# เกมคูณแต้ม Tell Tea (ชุด 3 เกม · เลือกได้ 1)

อัปเดต: 2026-08-12

หลังลูกค้าได้แต้มจากบิลทุกครั้ง → **เลือกเล่นได้เพียง 1 เกม** ลุ้นตัวคูณ ×1–×5  
ธีม: ชาไข่มุก / ชานม / ชาไทย + ซอฟคุกกี้ / บราวนี่ / ชิโอปัง · โลโก้หนุ่ม Tell Tea  
กลุ่มเป้า: อายุประมาณ **15–25**

## กฎลูกค้า (ล็อก)

| ข้อ | ความหมาย |
|-----|----------|
| ก่อนสมัคร/ล็อกอิน | เห็น **3 เกมเคลื่อนไหวเป็นพื้นหลัง** — ดึงดูด แต่ยังแตะเล่นไม่ได้ |
| หลังได้แต้มฐาน | เลือกเกมได้ **เพียง 1 เกม** ต่อรอบเคลม/สมัคร |
| เลือกแล้ว | เปลี่ยนเกมไม่ได้ · เล่นจนจบ |

## ชุดเกม

| # | เกม | เล่นยังไง |
|---|-----|-----------|
| **1** | **หมุนกระดานเมนู** | แถบเมนูเลื่อน · กดหยุด |
| **2** | **ป้อนไข่มุก** | ไข่มุกโยก · แตะป้อนเข้าปากตัวละครในโลโก้ |
| **3** | **เทชาไทยให้พอดี** | กดค้างเทชา · ปล่อยตอนระดับที่อยากได้ |

### เมนู = ตัวคูณ (ค่าเริ่ม)

| × | เมนู | ≈โอกาส |
|---|------|--------|
| ×1 | ชาไทย | 50% |
| ×2 | ชานมไข่มุก | 28% |
| ×3 | ซอฟคุกกี้ | 14% |
| ×4 | บราวนี่ | 6% |
| ×5 | ชิโอปัง | 2% |

**EV ≈ 1.82×**

## โฟลว์

```text
สแกน QR
  → หน้าสมัคร/ล็อกอิน + พื้นหลัง 3 เกมเคลื่อนไหว
  → สมัคร / เข้าสู่ระบบ / รับแต้มฐาน
  → เลือก 1 เกม → เล่น → จบ
  → แต้ม = ฐาน × ตัวคูณ   ← เฟสเซิร์ฟเวอร์
```

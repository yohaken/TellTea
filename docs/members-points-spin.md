# เกมคูณแต้ม Tell Tea (ชุด 3 เกม)

อัปเดต: 2026-08-12

หลังลูกค้าได้แต้มจากบิลทุกครั้ง → ลุ้นตัวคูณ ×1–×5  
ธีม: **ชาไข่มุก / ชานม / ชาไทย + ซอฟคุกกี้ / บราวนี่ / ชิโอปัง** · โลโก้หนุ่ม Tell Tea  
กลุ่มเป้า: อายุประมาณ **15–25** (ศูนย์กลาง ~20)

## ชุดเกมที่ล็อกไว้

| # | เกม | เล่นยังไง | ทำไมเหมาะ |
|---|-----|-----------|-----------|
| **1** | **หมุนกระดานเมนู** | แถบเมนูเลื่อน · กดหยุด | เห็นสินค้าจริง · ชิ้นแคบ = ยาก |
| **2** | **ป้อนไข่มุก** | ไข่มุกโยกบนเลน · แตะป้อนเข้าปากตัวละครในโลโก้ | ใช้แบรนด์ชัด · น่ารัก ไม่เด็กเกิน |
| **3** | **เทชาไทยให้พอดี** | กดค้างเทชา · ปล่อยตอนระดับที่อยากได้ | ทักษะสั้นๆ แบบมือถือ · จบเร็ว |

ลูกค้าแต่ละครั้งสุ่มได้ **1 ใน 3 เกม** (หรือร้านล็อกเกมเดียวตอนเปิดจริง — เฟส S4)

### เมนูบนกระดาน = ตัวคูณ

| × | เมนู | โอกาสเริ่ม |
|---|------|------------|
| ×1 | ชาไทย | 50% |
| ×2 | ชานมไข่มุก | 28% |
| ×3 | ซอฟคุกกี้ | 14% |
| ×4 | บราวนี่ | 6% |
| ×5 | ชิโอปัง | 2% |

**EV ≈ 1.82×** — ปรับน้ำหนักได้ที่หน้าจำลอง

## ทำไม «ป้อนไข่มุกเข้าปากโลโก้» ดี

- โลโก้เป็น**ผู้ชาย + ชาไข่มุก** — เกมนี้ใช้ตัวละครแบรนด์โดยตรง
- กลุ่ม 15–25 คุ้นเกมจับจังหวะสั้นๆ
- โซนแคบใกล้ปาก = × สูง → สื่อความยากชัดโดยไม่ต้องอ่านตัวหนังสือเยอะ

## โฟลว์ลูกค้า (เป้า)

```text
สแกน QR
  → เห็นเกมธีมชา/ขนมทันที (ทีเซอร์)
  → สมัคร / เข้าสู่ระบบ / รับแต้มฐาน
  → เล่น 1 เกม (หมุน / ป้อนไข่มุก / เทชา)
  → แต้ม = ฐาน × ตัวคูณ   ← เฟสเซิร์ฟเวอร์
```

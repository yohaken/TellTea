# ออกแบบใบเสร็จจากหลังร้าน — เฟสยาว

อัปเดต: 2026-08-09  
สถานะ: **D1–D2 หลังร้าน+ซิงก์ธง · กระดาษ native ยังเป็น D3**

เป้าหมาย: เจ้าของแก้ **โลโก้ / ข้อความหัว–ท้ายสลิป** จากหลังร้านแล้วเห็นผลบนใบเสร็จจริง โดยไม่ต้องอัปเดต APK ทุกครั้งที่เปลี่ยนคอนเทนต์  
เรนเดอร์ใบเสร็จใช้ **ฟอร์มล่าสุดเท่านั้น** (unified / อ่านง่าย) — **ห้ามถอยเทมเพลตเก่า**

ของที่มีแล้ว (ฐาน):

| ของเดิม | ที่อยู่ |
|---------|---------|
| ตั้งค่าหัวบิล + พรีวิวใบเสร็จ/X/Z | `/pos-sales` → จัดการร้าน → แท็บ **บิล** (`PosBusinessSettingsView`) |
| เรนเดอร์ล่าสุด | `buildUnifiedReceiptBody` · `ReceiptFormBuilder` · `receipt-text-form` |
| ซิงก์ร้าน → เครื่อง | `meta/pos` + `nposShopSettings` → `shopJson` |
| โลโก้ร้าน | `meta/brandLogo` (ขึ้นจอแอปแล้ว · **ยังไม่พิมพ์บนกระดาษ**) |
| พาริตี้ / อ่านง่าย | `docs/npos-receipt-parity-checklist.md` · `docs/npos-receipt-readable-checklist.md` |

## หลักที่ล็อก (ไม่เปลี่ยนกลางทาง)

| ข้อ | ความหมาย |
|-----|----------|
| **ที่วางเดียว** | ออกแบบสลิปอยู่ที่แท็บ **บิล** ในจัดการร้าน — ไม่สร้างหน้าแยกใหม่ |
| **เรนเดอร์ล่าสุดเท่านั้น** | พรีวิว = กระดาษ = ฟอร์ม unified ปัจจุบัน · ไม่มีสวิตช์กลับแบบเก่า |
| **คอนเทนต์ ≠ APK** | เปลี่ยนโลโก้/ข้อความจากหลังร้านได้หลังซิงก์ · APK เฉพาะตอนเพิ่มความสามารถพิมพ์ใหม่ |
| **พิมพ์มาก่อนเสมอ** | โลโก้/เรนเดอร์พิเศษพัง → ยังพิมพ์ข้อความครบ · ห้ามสะดุดคิวพิมพ์ |
| **คุณเทสเองก่อนเปิดจริง** | ข้อความจำง่ายบนพรีวิว → ซิงก์เครื่อง → ขาย/พิมพ์ซ้ำ 1 ใบดูกระดาษ |
| **ไม่แตะเดลิเวอรี่แอพ** | ใบเสร็จนี้ = สลิป nPos หน้าร้านเท่านั้น · ไม่ดักพิมพ์ Grab/LM/Shopee |

### คำตอบเจ้าของ (ล็อก 2026-08-09)

| ข้อ | ตัดสิน |
|-----|--------|
| **1. ค่าเริ่มโลโก้บนสลิป** | **เปิดเลย** เมื่อมีรูปใน `meta/brandLogo` (อัปหลังร้านแล้ว) — ไม่ต้องเปิดธงทีหลังเอง |
| **2. เครื่องพิมพ์เป้า** | **เครื่องเดิมที่ใช้หน้าร้านตอนนี้** (Sunmi InnerPrinter path) — D3 คือเส้นทางหลัก · D4 USB/BT/LAN เป็นพาริตี้สำรอง ไม่บล็อกเปิดใช้ |
| **3. โลโก้ตอนพิมพ์ / พิมพ์ซ้ำ** | ใช้โลโก้จาก **หลังร้านชุดปัจจุบัน** (`meta/brandLogo` + จุดออกแบบสลิปในแท็บบิล) เสมอ · **ไม่**ย้อนรูปต่อบิลเก่า |

### เลย์เอาต์หัวสลิปเป้าหมาย

```text
        [โลโก้]          ← กลาง · ขนาดจำกัด · เปิด/ปิดได้
     ชื่อร้าน EN/TH
      ที่อยู่ · โทร · ภาษี
         ใบเสร็จ
      …รายการ / ยอด…     ← ฟอร์มล่าสุดคงเดิม
   QR สะสมแต้ม (ถ้ามี)   ← อยู่ท้าย · ไม่ย้ายขึ้นหัว
      ข้อความท้ายใบ
```

โลโก้**ไม่**ซ้ำท้ายใบ · **ไม่**วางข้าง QR

## D1 — หลังร้าน: จุดออกแบบ + พรีวิวโลโก้

หน้า: `/pos-sales` → จัดการร้าน → แท็บ **บิล** (ขยายของเดิม)

- [x] ส่วน «หัวสลิป» ชัด: โลโก้บนใบเสร็จ · ชื่อ · ที่อยู่ · โทร · ภาษี · พนักงานบนบิล · ท้ายใบ
- [x] โลโก้: ใช้ `meta/brandLogo` ชุดเดียวกับทั้งแอป · อัป/เปลี่ยนในแท็บบิล (`BusinessLogoField`)
- [x] สวิตช์ **แสดงโลโก้บนใบเสร็จ** (ค่าหลังร้าน) — **ค่าเริ่มเปิดเมื่อมีรูป** · พรีวิวสะท้อนทันที · ใช้ปิดเป็นทางหนีถ้าพิมพ์พัง
- [x] `DocPreview` แท็บใบเสร็จ: เรนเดอร์โลโก้บนหัวด้วย **`buildUnifiedReceiptBody` / unified styles เท่านั้น**
- [x] พรีวิวเคสเดิม (เงินสด/ทอน ฯลฯ) ยังใช้ได้
- [x] ไม่มี UI เลือกเทมเพลตเก่า / ธีมกระดาษย้อนหลัง

**เกณฑ์จบ:** แก้ท้ายใบหรือเปิดโลโก้ในพรีวิวแล้วเห็นทันทีหลังร้าน · ยังไม่บังคับว่าเครื่องพิมพ์รูปแล้ว · ✅ โค้ดพร้อม — คุณดูพรีวิวในแท็บบิล

## D2 — โมเดลซิงก์ (ไม่พึ่ง APK ตอนเปลี่ยนคอนเทนต์)

เก็บค่าใน `meta/pos` (หรือฟิลด์คู่ที่ตกลงในเฟสนี้) แล้วส่งออก `nposShopSettings`:

| ฟิลด์ (ร่าง) | ความหมาย |
|--------------|----------|
| `receiptPrintLogo` | boolean — พิมพ์โลโก้บนสลิปหรือไม่ · **ค่าเริ่ม `true` เมื่อมี `brandLogo`** (เจ้าของล็อกแล้ว) |
| `brandLogo` | data URL จาก `meta/brandLogo` ที่อัปหลังร้านแล้ว (แคปขนาดเดิมใน API) |
| ฟิลด์หัวบิลเดิม | `shopName` · `shopNameTh` · `shopAddress` · `shopPhone` · `taxId` · `receiptStaffName` · `receiptFooterNote` |

- [x] บันทึกจากแท็บบิลขึ้น Firebase ชุดเดียวกับหัวบิลเดิม (`receiptPrintLogo`)
- [x] `nposShopSettings` ส่ง `receiptPrintLogo` (+ `brandLogo` เหมือนเดิม)
- [x] native อ่าน `receiptPrintLogo` เข้า `shopJson` แล้วใช้ตอนพิมพ์ — **D3**
- [x] ไม่มีรูปโลโก้ → พรีวิวไม่มีโลโก้ · มีรูป + ธงเปิด → พรีวิวมีโลโก้
- [x] นโยบาย: ขายใหม่/พิมพ์ซ้ำใช้โลโก้ชุดปัจจุบัน — native ทำใน D3

**เกณฑ์จบ:** ธงขึ้น Firebase + API แล้ว · กระดาษ = D3 / APK 148

## D3 — กระดาษ: เครื่องเดิม (InnerPrinter) — เส้นทางหลัก

เครื่องหน้าร้านที่ใช้ตอนนี้ (bitmap / Sunmi InnerPrinter)

- [x] มี `brandLogo` → พิมพ์โลโก้กลางเหนือชื่อร้านเป็นค่าเริ่ม (`receiptPrintLogo` เปิด)
- [x] วาดใน `SunmiSlipBitmap` / `printSlip`
- [x] จำกัดความกว้าง ~40–50% ความกว้างกระดาษ · สูงไม่เกินเพดานที่กำหนดในโค้ด
- [x] **fail-open:** decode รูปพัง / รูปใหญ่เกิน → ข้ามโลโก้ พิมพ์ข้อความต่อ ไม่ค้างคิว
- [x] ไม่ผูก AIDL ค้างหลังจบงาน (นโยบายปล่อยเครื่องเดิม)
- [x] QR claim / รายการ / ตัวหนา ฟอร์มล่าสุดไม่ถูกรื้อ
- [x] พิมพ์ซ้ำ: ดึงโลโก้ชุดปัจจุบันจากหลังร้าน/`shopJson` ไม่เก็บรูปต่อ sale
- [x] เกต `test-npos-receipt-logo-d3` · APK **148**

**เกณฑ์จบ:** โค้ดพร้อม OTA · คุณขาย 1 บิลบนเครื่องเดิมยืนยันกระดาษ (D5)

**อัป APK รอบนี้ครั้งเดียว (148)** — หลังจากนั้นเปลี่ยนรูปที่หลังร้าน / จุดออกแบบสลิปอย่างเดียว

## D5 — คุณเทสเคาน์เตอร์ (บังคับก่อนเปิดจริง)

ทำเองทีละข้อ · ติ๊กเมื่อกระดาษตรงพรีวิว

### คอนเทนต์โดยไม่ลง APK ใหม่ (หลัง D3 ลงแล้ว)

- [ ] เปลี่ยนท้ายใบเป็นข้อความจำง่าย (เช่น `เทสท้ายใบ-YYYYMMDD`) → บันทึก → พรีวิวขึ้น
- [ ] เปิด nPos ให้ซิงก์ร้าน → ขายหรือพิมพ์ซ้ำ 1 ใบ → กระดาษมีข้อความนั้น
- [ ] เปลี่ยนชื่อร้านสั้นๆ ชั่วคราว → กระดาษตาม → คืนค่าเดิม
- [ ] เปลี่ยนโลโก้หลังร้าน → พรีวิวขึ้นรูปใหม่ → ขาย 1 ใบดูกระดาษ (ไม่ลง APK)
- [ ] ปิด «แสดงโลโก้บนใบเสร็จ» → กระดาษไม่มีโลโก้ ข้อความครบ

### ไม่ regress ฟอร์มล่าสุด

- [ ] qty ASCII · เว้นบรรทัดรายการ · ชื่อตัวหนา ยังอยู่
- [ ] QR สะสมแต้ม (ถ้าธงสมาชิกเปิด) ยังท้ายใบ ข้อความเชิญไม่หาย
- [ ] เงินสดมีทอน / พร้อมเพย์ไม่มีแถวทอน
- [ ] พิมพ์ซ้ำจากประวัติได้
- [ ] ปิดกะ / X / Z ยังพิมพ์ได้ ไม่ปนฟอร์มใบเสร็จลูกค้า

### สมรรถนะพิมพ์

- [ ] หลังปิดบิลได้กระดาษเร็วใกล้เคียงเดิม (ไม่รอซิงก์)
- [ ] ไม่เจอค้างพิมพ์ / กระดาษขาว / แอพเดลิเวอรี่เครื่องเดียวกันพิมพ์ไม่ออกหลังขาย nPos

**เกณฑ์จบ:** คุณยืนยันเองว่าพรีวิว = กระดาษ · คอนเทนต์แก้จากหลังร้านได้จริง

## D6 — เปิดใช้จริง

- [ ] ค่าเริ่มตามล็อกเจ้าของ: มีโลโก้ใน `meta/brandLogo` → **พิมพ์โลโก้เลย** (ไม่รอเปิดมือ)
- [ ] จุดออกแบบสลิปในแท็บบิลเป็นที่เปลี่ยนโลโก้/ข้อความต่อจากนี้
- [ ] คัดลอกเช็กลิสต์สั้นไว้ใกล้แท็บบิล (ข้อความจำง่าย → ซิงก์ → 1 ใบ)

- [ ] ถ้าพังการพิมพ์ → ปิดแสดงโลโก้จากหลังร้านได้ทันทีโดยไม่รอ APK

**เกณฑ์จบ:** ใช้จริงรายวันบนเครื่องเดิม · ปิดโลโก้เป็นทางหนีทีละทาง

## D7 — ขยายหลังนิ่ง (ไม่บล็อก D6)

ทำทีละชิ้นเมื่อ D6 นิ่งแล้ว

- [ ] แก้ข้อความเชิญใต้ QR เคลมจากหลังร้าน (สั้น · จำกัดความยาว 58mm)

## โฟลว์คุณเทส (สรุปติดผนัง)

```text
หลังร้านแท็บบิล
  → แก้ข้อความจำง่าย / โลโก้ / ธง
  → ดูพรีวิว (ฟอร์มล่าสุด)
  → บันทึก Firebase
       ↓
แท็บเล็ต nPos ซิงก์ร้าน
       ↓
ขาย 1 บิล หรือพิมพ์ซ้ำ
       ↓
กระดาษ = พรีวิว → ผ่าน
```

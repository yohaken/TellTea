# nPos — รอบการขาย ↔ เทียบเงินนำเข้า

อัปเดต: **APP_BUILD 566** · **POS_BUILD 162** · เฟส R1–R3

เป้า: พนักงาน/เจ้าของเห็นว่าแต่ละรอบที่ปิดแล้ว **ต้องนำส่งเงินตามจริง** ·
ผูกกับตารางเทียบเงินนำเข้า · และเพิ่มรอบมือสำหรับเคาน์เตอร์นอกโปรแกรม

อ้างอิงสูตร Z: [npos-z-cash-remit-checklist.md](./npos-z-cash-remit-checklist.md) ·
รายละเอียดเงินรอบ: [npos-session-cash-detail-checklist.md](./npos-session-cash-detail-checklist.md)

---

## สูตรที่ล็อก (ไม่เปลี่ยน)

| แถว | สูตร |
|-----|------|
| ควรมีในลิ้นชัก | `เริ่มต้น + ขายสด − เงินออก + เงินเข้า` |
| ยอดที่ต้องนำส่ง | `max(0, นับจริง − ทอนรอบถัดไป)` → `remitAmount` |
| ส่งเงินมือ | `handed − remitAmount` → 0 = ตรง · ≠0 = ไม่ตรง |
| เงินนำเข้า | `(เข้าบัญชี + คชจ.) − Σ cashAmount` · cashAmount ดึงจาก `remitAmount` ได้เมื่อผูกรอบ |

## ลำดับเฟส

```
R1 เช็คลิสส่งเงินต่อรอบ → R2 ผูกเงินนำเข้า ← remit → R3 รอบมือ (นอกโปรแกรม)
```

## R1 — เช็คลิสส่งเงินต่อรอบ (handoff) · **ship 565**

**ปัญหา:** ปิดรอบแล้วมี `remitAmount` / สลิป Z แต่หลังร้านไม่รู้ว่ารอบนั้น **ส่งเงินแล้วหรือยัง**  
**เป้า:** รอบปิด → สถานะค้างส่ง · บันทึกยอดที่รับจริง + ผู้ส่ง/ผู้รับ → ตรง / ไม่ตรง  
**ไม่ทำ:** PIN พนักงาน · บังคับห้ามเปิดรอบใหม่ · แก้สูตรลิ้นชัก

### งาน
- [x] R1.1 โมเดล `remitStatus` / `remitHandedAmount` / ผู้ส่ง·ผู้รับ·โน้ต บน `PosSession`
- [x] R1.2 helper + `recordPosSessionRemitHandoff` / `clearPosSessionRemitHandoff`
- [x] R1.3 `/pos-sales` แสดงสถานะส่งเงิน + ฟอร์มใน expand
- [x] R1.4 Gate `scripts/test-npos-remit-rounds.mjs`

**จบเมื่อ:** ปิดรอบมีนำส่ง → โชว์ «ค้าง» → บันทึกยอดรับ → «ส่งแล้ว» หรือ «ไม่ตรง»

## R2 — ผูกเทียบเงินนำเข้า ← ยอดนำส่งรอบ · **ship 565**

**ปัญหา:** ตารางเงินนำเข้าใช้ยอดขายเงินสดจากสลิป · ไม่ดึง `remitAmount` จากรอบที่ปิด  
**เป้า:** แถววันในรอบฝากผูก `sessionIds[]` ได้ · เติม `cashAmount` = Σ remit ของรอบที่เลือก  
**ไม่ทำ:** เปลี่ยนสูตร variance ธนาคาร · AI อ่าน remit อัตโนมัติ (ยังใช้ cash sales จากรูปได้)

### งาน
- [x] R2.1 `CashDepositDayLine.sessionIds` + normalize/persist
- [x] R2.2 helper `fillDayCashFromSessions` / `sessionsForCashDepositDay`
- [x] R2.3 UI เงินนำเข้า: ปุ่มดึงจากรอบ nPos ต่อวัน
- [x] R2.4 Gate ใน `test-npos-remit-rounds.mjs`

**จบเมื่อ:** เลือกวัน → ดึงรอบปิดของวันนั้น → ยอดขายเงินสดในแถว = Σ นำส่ง

---

## R3 — รอบมือ (เคาน์เตอร์นอกโปรแกรม) · **ship 565**

**ปัญหา:** เคาน์เตอร์ที่ยังไม่ใช้ nPos ไม่มีแถวใน `/pos-sales` ให้เทียบส่งเงิน  
**เป้า:** เจ้าของสร้างรอบ `source: manual` จากหลังร้าน (ปิดแล้ว) · เข้าเช็คลิสส่งเงินชุดเดียวกับ nPos  
**ไม่ทำ:** สร้าง device seat · ซิงก์บิลปลอม · เปิดรอบมือค้างบนแท็บเล็ต

### งาน
- [x] R3.1 `createManualPosSession` + rules อนุญาต owner create
- [x] R3.2 UI `+รอบมือ` บนตารางรอบ
- [x] R3.3 Gate ใน `test-npos-remit-rounds.mjs`

**จบเมื่อ:** สร้างรอบมือใส่ยอดนำส่ง → ขึ้นในตาราง · สถานะค้างส่ง · บันทึกส่งเงินได้

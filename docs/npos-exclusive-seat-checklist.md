# nPos — Exclusive seat · รหัสลับ 1:1 · ตารางเครื่องหลังบ้าน

อัปเดต: **แผน** (ยังไม่ ship โค้ด) · อ้างอิงหลัง `1.14.27`  

เป้าหมาย: ลูกค้ากรอกรหัสลับตรงกับหลังบ้าน **1:1** · **เครื่องเดียวถือสิทธิ์ขาย** · หลังบ้านเห็นสถานะแบบคอมแพค · เตะได้ · เครื่องที่ถูกเตะเด้งใส่รหัส + เช็คอัปเดตเป็นระยะ

อ้างอิงของเดิม: `docs/npos-store-claim-checklist.md` (multi-claim) · แผง `PosStoreClaimPanel` · `nposClaimDevice` · `posDevices`

---

## นโยบายที่ล็อก

| หัวข้อ | ตัดสิน |
|--------|--------|
| รหัสลับ | ตั้งหลังบ้าน · เก็บ **hash** · เครื่องกรอกตรง 1:1 |
| Seat | **exclusive** — เคลมสำเร็จได้ทีละ 1 `installId` |
| เคลมตอนมีคนถือ seat | ปฏิเสธ `seat_taken` (ไม่แย่งอัตโนมัติ — ค่าเริ่มต้นเข้ม) |
| เตะจากหลังบ้าน | เสียสิทธิ์เขียนทันที · เด้งหน้าใส่รหัส |
| กะตอนเตะ | **ไม่ตัดกะอัตโนมัติ** · กะอยู่บนเซิร์ฟเวอร์จนกว่าปิดปกติ / ปุ่มบังคับปิดแยก |
| เครื่องใหม่หลังเตะ | resume กะที่ยังเปิดอยู่ได้ (เมื่อได้ seat ใหม่) |
| อัปเดต | หน้าใส่รหัส poll `latest.json` เป็นระยะ (ด่านบังคับ) |

นอกสcope เฟสนี้: multi-device คู่ขนานเป็นค่าเริ่มต้น · KDS · เว็บปิดกะ

## สถานะเครื่อง (มาตรฐานตาราง slim)

คอลัมน์: `ชื่อ/รหัส · สถานะ · เชื่อมต่อ · เวอร์ชัน · กะ · แอ็กชัน`

| สถานะ | ความหมาย |
|--------|----------|
| **ว่าง** | ยังไม่มีใครถือ seat |
| **ออนไลน์** | ถือ seat + heartbeat สด |
| **หลุดเน็ต** | ถือ seat แต่ heartbeat ขาด |
| **ถูกเตะ** | revoke แล้ว · ต้องใส่รหัสใหม่ |
| **รหัสผิดซ้ำ** | ล็อกชั่วคราวหลังพลาดหลายครั้ง (S4+) |
| **เวอร์ชันเก่า** | APK ต่ำกว่า latest |
| **บล็อก** | แบนเครื่อง |

เชื่อมต่อ: `ออนไลน์` / `หลุด` / `ไม่เคยฮาร์ทบีต`

## S1 — Exclusive seat + เตะแล้วเด้งใส่รหัส

### เซิร์ฟเวอร์
- [ ] S1.1 `meta/pos` มี `activeSeatInstallId` (หรือเทียบเท่า) + `seatMode: "exclusive"`
- [ ] S1.2 `nposClaimDevice`: รหัสถูก + seat ว่าง → ตั้ง seat = install นี้ · `storeClaimed: true`
- [ ] S1.3 `nposClaimDevice`: รหัสถูกแต่ seat ถูกเครื่องอื่นถือ → `403 seat_taken` + ข้อความไทยสั้น
- [ ] S1.4 `assertNposDeviceAllowed`: ต้องเป็นเครื่องที่ถือ seat (ไม่ใช่แค่ claimed)
- [ ] S1.5 revoke/เตะ: เคลียร์ seat + `storeClaimed: false` บนเครื่องนั้น · เหตุผล `kicked`
- [ ] S1.6 heartbeat ส่งกลับ: `seatHeldByMe` · `seatTaken` · `kicked` · `storeClaimRequired`

### Native
- [ ] S1.7 หน้าเข้างาน: บังคับกรอกรหัสเมื่อเกตเปิดและยังไม่ถือ seat
- [ ] S1.8 เมื่อ heartbeat/`device_not_allowed` บอกถูกเตะ → เคลียร์ claim local · ปิดหน้าขายถ้าเปิดอยู่ · เด้งใส่รหัส
- [ ] S1.9 Toast/แบนเนอร์: `seat_taken` / `ถูกถอนสิทธิ์จากหลังบ้าน` ภาษาคน
- [ ] S1.10 Gate สคริปต์ assert exclusive paths ใน CF + prefs

**จบ S1 เมื่อ:** เครื่อง A เคลมได้ · B โดน seat_taken · เตะ A แล้ว A เด้งใส่รหัส · A ขายไม่ได้จนกว่าเคลมใหม่

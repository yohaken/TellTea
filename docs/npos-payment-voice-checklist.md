# nPos — เสียงพูดรับเงิน / ทอน (Android TTS)

อัปเดต: **ship O4 → 1.14.88** · ดูเฟส [npos-counter-ops-phases.md](./npos-counter-ops-phases.md)  
อ้างอิง: [npos-change-display-setting-checklist.md](./npos-change-display-setting-checklist.md) · แถบทอน (1.14.85+)

## เป้า
หลังขายสด พูดไทยสั้น: **«รับมา X บาท ทอน Y บาท»**  
สวิตช์เปิด/ปิดใน **ตั้งค่า → การชำระเงิน** · ค่าเริ่มต้นเปิด

## วิเคราะห์สถานการณ์จริง (ต้องไทย)

| ข้อ | ความจริงหน้างาน | ทางเลือกในแอป |
|-----|------------------|----------------|
| Engine | SUNMI มักมี TTS จีน/อังกฤษเป็นหลัก · ไทยต้องมี Google TTS หรือแพ็กภาษาไทย | เช็ค `isLanguageAvailable(th_TH)` ก่อนพูด |
| `LANG_AVAILABLE` / `LANG_COUNTRY_AVAILABLE` | พูดไทยได้จริง | ใช้ `Locale("th","TH")` + ประโยคไทย |
| `LANG_MISSING_DATA` | ยังไม่ดาวน์โหลดเสียงไทย | **ไม่ครASH** · เงียบ + log ครั้งเดียว · แสดงในตั้งค่าว่า «ยังไม่มีเสียงไทย» |
| `LANG_NOT_SUPPORTED` | เครื่องไม่มีไทยเลย | เหมือน missing · **ไม่ fallback อังกฤษ** (กันพูดผิดภาษา) |
| ตัวเลข | Google TTS อ่านเลขอารบิกในประโยคไทยได้ดี | ใช้ `%.0f` ในประโยคไทย |
| เน็ต | Offline TTS พอถ้าแพ็กติดตั้งแล้ว | ไม่พึ่ง cloud เป็นหลัก |
| ค่าเริ่ม | ต้องการได้ยินทันที | สวิตช์ **เปิด** · ถ้าไทยใช้ไม่ได้จะเงียบเอง |

**สรุป:** บังคับไทยเท่านั้น · ไม่พูดอังกฤษแทน · ถ้าเครื่องไม่มีเสียงไทย = เงียบ + บอกในตั้งค่า

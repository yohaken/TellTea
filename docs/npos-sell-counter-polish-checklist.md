# nPos — เคาน์เตอร์ขายหน้าร้าน (เมนู / ตะกร้า)

อัปเดต: **1.14.42** · `APP_BUILD` 299 · `POS_BUILD` 94 · vc **64**  
มติเคาน์เตอร์ (2026-07-28): หน้าร้านล้วน · ไม่ใช่แอพเดลิเวอรี่ · ไม่เปิดโต๊ะ

## นโยบายล็อก

| หัวข้อ | มติ |
|--------|-----|
| PromptPay บน native | **ยังไม่เปิด** — ร้านยังไม่ใช้ · ฝากไว้ด้านล่าง (P-PP) |
| ราคา / ช่องทางส่ง | **ตัดออกจาก POS** — หน้าที่แอพเดลิเวอรี่ · หน้าร้านใช้ราคา `store` อย่างเดียว |
| โต๊ะ / ลูกค้า / ทานในร้าน·กลับบ้าน | ไม่ทำ |
| โน้ตออร์เดอร์ / สต็อกคงเหลือ | นอกสcope |
| Void บนหน้าขาย | ไม่ทำ — อยู่หน้าใบเสร็จ |

## โปรเซสเคาน์เตอร์

```
เลือกหมวด → จิ้มเมนู → option
  → แก้จำนวนในตะกร้า (± / ลบ) · เห็นราคาแถวชัด
  → (ถ้ามี) ส่วนลด
  → จ่ายเงินสด
  → พิมพ์ตามตั้งค่า → บิลถัดไป
```

## C0 ตัดระบบส่งออกจาก POS

- [x] native: ลบปุ่มสลับ `หน้าร้าน / ส่ง` จากตะกร้า
- [x] native: ราคาเมนู/ออปชันใช้ `store` อย่างเดียว (`item.price` / `priceDelta`)
- [x] เว็บขาย (ถ้ายังมี): ตัดสลับช่องทางราคา ส่ง
- [x] สตริง `price_channel_*` ไม่โชว์บนหน้าขาย (เก็บหรือลบได้)
- [ ] เมนูแอดมิน: ช่อง `deliveryPrice` — คงในข้อมูลได้ แต่ไม่โชว์บน POS ขาย (ไม่บังคับรอบนี้)

## C1 สรุปยอดตะกร้า (UI)

- [x] แถว **ยอดรวม** (subtotal) เสมอ
- [x] แถว **ส่วนลด** (โชว์เมื่อมี · หรือ `—` เมื่อไม่มี — เลือกแบบอ่านง่าย)
- [x] แถว **ยอดสุทธิ** เด่น (ตัวใหญ่ / น้ำหนัก)
- [x] Prompt + สีแบรนด์ · ไม่การ์ดซ้อน · ไม่ม่วง/ครีมเทอร์ราคอต

## C2 จัดกลุ่มปุ่มคำสั่ง

- [x] แถวรอง: ส่วนลด · พักบิล · ดึงบิลพัก · ล้างตะกร้า
- [x] แถวหลัก: **เงินสด** (สูงชัด · SellRow Primary)
- [x] PromptPay ปุ่มยัง **GONE** (ดู P-PP)
- [x] X-report / ซิงก์ค้าง อยู่รอง ไม่แย่งปุ่มจ่าย

## C3 แถวรายการตะกร้า

- [x] ชื่อเมนู + ออปชันคนละบรรทัด
- [x] ราคารวมแถวชิดขวา อ่านง่าย

- [x] แตะชื่อ/ออปชัน → แก้ option (ของเดิม)

## C4 หัวตะกร้า + พักบิล

- [x] หัวตะกร้า: คำว่าตะกร้า + เลขอ้างอิงสั้นเมื่อมีรายการ (เช่น `#รอส่ง-…` ชั่วคราวจาก mutation preview หรือ “บิลใหม่”)
- [x] ปุ่มดึงบิลพัก: มีสัญญาณเมื่อ `HoldCart.hasHold()` (ข้อความ/ชิป)
- [x] พักบิลยัง slot เดียว (ไม่ทำ multi-hold รอบนี้)

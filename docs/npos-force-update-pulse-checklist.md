## มติ

| พฤติกรรม | รายละเอียด |
|----------|------------|
| เช็คเวอร์ชันบน sync pulse | หลัง heartbeat สำเร็จ |
| เวอร์ชันไม่ตรง | ป๊อบอัปเดตบังคับ · **ไม่มี**ปุ่ม Later / snooze |
| กำลังขาย (ตะกร้ามีของ) | **เลื่อน** — ไม่โชว์/ไม่ติดตั้งจนกว่าจะว่าง |
| ว่างแล้ว | ป๊อบ + เสียงเตือน + ติดตั้งเอง · ขอสิทธิ์ติดตั้งถ้ายังไม่มี |
| ปิดผิด / กดพลาด | pulse + resume โชว์ใหม่ทันที |
| ปุ่มรีเฟรชหน้าร้าน | ซ่อน |

# ผสาน VAT สองบช. → VAT เดือน

> อัปเดต 2026-07-29 · `/ledger/` · `/owner-books/` · `/vat-sales/`

---

## ภาพรวม

```
บช.พนักงาน / บช.เจ้าของ
  บันทึกบิล + AI อ่านยอดภาษี (hasVat · ยังไม่รวมหัก)
        │
        ▼
VAT เดือน → ตาราง + รายการจากสองบช.
  · ดูรายการทันที (แตะแถว = มุมมองแบบบช.)
  · ติ๊ก「รวมเข้าระบบ」(vatClaim)
        │
        ▼
กด「ดึงภาษีซื้อจากสองบช.」→ วัตถุดิบหน้าร้าน
  (เฉพาะรายการที่ติ๊ก รวม · GP เดลิเวอรี่แยก)
```

---

## ขั้นตอนใช้จริง

1. **บันทึกบิลซื้อ** ในบช.พนง. หรือบช.เจ้าของ — AI อ่านยอดภาษีเก็บไว้ (ยังไม่รวมหักอัตโนมัติ)
2. ไป **VAT เดือน** → ตารางภาษีซื้อ → กด **`+` รายการจากสองบช.**
3. **แตะรายการ** เปิดมุมมองเหมือนบช. (รูปใบเสร็จ · ยอด · ช่อง VAT) ตรวจว่าหักได้จริง
4. ติ๊ก **รวมเข้าระบบ** ทีละรายการ หรือติ๊กหัวตารางรวมยอดทั้งหมด (เริ่มต้นยังไม่ติ๊ก)
5. ครั้งหน้าเจอรายการเดิม — จำติ๊กไว้แล้ว ไม่ต้องติ๊กซ้ำ
6. กด **ดึงภาษีซื้อจากสองบช.** → ใส่รวมเข้า **ภาษีซื้อวัตถุดิบ (หน้าร้าน)**
7. บันทึกร่าง / ปิดงบตามปกติ

---

## ฟิลด์

| ฟิลด์ | ความหมาย |
|------|----------|
| `hasVat` + `vatInput` | มียอดภาษีซื้อบนบิล / เก็บในรายการ |
| `vatVerified` | คนตรวจแล้วว่าตรงบิล |
| `vatClaim` | รวมเข้าหัก VAT เดือน (ติ๊กที่ตารางเดือน) |

รายการเก่าที่ยังไม่มี `vatClaim` แต่มี `hasVat`+`vatInput` → นับว่า claim แล้ว (กันยอดเดือนเดิมหาย)

---

## กฎสำคัญ

| กฎ | เหตุผล |
|----|--------|
| **อย่าคีย์บิลซ้ำสองบช.** | จะนับภาษีซื้อซ้ำ |
| AI ไม่ auto รวมเข้าระบบ | บางบิลมียอด VAT แต่หักไม่ได้ |
| GP ≠ วัตถุดิบ | GP = ก้อนแพลตฟอร์มเดลิเวอรี่ · วัตถุดิบ = บิลที่ติ๊กรวมจากสองบช. |
| ดึงแล้วแก้เองได้ | ตัวเลขในช่องวัตถุดิบแก้มือได้หลังดึง |

# ผสาน VAT สองบช. → VAT เดือน

> อัปเดต 2026-07-29 · `/ledger/` · `/owner-books/` · `/vat-sales/`

---

## ภาพรวม

```
บช.พนักงาน (ledger)     บช.เจ้าของ (ownerBooks)
  รายการออก + ติ๊ก VAT      รายการออก + ติ๊ก VAT
        │                         │
        └──────────┬──────────────┘
                   ▼
         รวม vatInput ของเดือน
                   ▼
     VAT เดือน → ช่อง「ภาษีซื้อวัตถุดิบ」หน้าร้าน
                   +
              GP เดลิเวอรี่ (แยก · ไม่ดึงจากบช.)
                   ▼
              ภาษีซื้อรวม = GP + วัตถุดิบ
```

---

## ขั้นตอนใช้จริง

1. **บันทึกบิลซื้อ** ในบช.พนง. หรือบช.เจ้าของ (แม็คโคร · ท็อปส์ · ท็อปแวลู ฯลฯ)
2. เปิดรายการ → ติ๊ก **มีใบกำกับภาษี** → ตรวจยอดภาษีซื้อ (เสนอ ×7/107)
3. ไป **VAT เดือน** → ตารางภาษีซื้อ → กด **ดึงภาษีซื้อจากสองบช.**
4. ระบบใส่รวมเข้า **ภาษีซื้อวัตถุดิบ (หน้าร้าน)** · GP คีย์/ประมาณแยกตามเดิม
5. บันทึกร่าง / ปิดงบตามปกติ

---

## กฎสำคัญ

| กฎ | เหตุผล |
|----|--------|
| **อย่าคีย์บิลซ้ำสองบช.** | จะนับภาษีซื้อซ้ำ |
| GP ≠ วัตถุดิบ | GP = ก้อนแพลตฟอร์มเดลิเวอรี่ · วัตถุดิบ = บิลร้านจากสองบช. |
| เงินเข้าไม่มีช่อง VAT | ใช้กับเงินออก / บิลซื้อเท่านั้น |
| ดึงแล้วแก้เองได้ | ตัวเลขในช่องวัตถุดิบแก้มือได้หลังดึง |

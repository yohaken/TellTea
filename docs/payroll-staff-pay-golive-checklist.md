# เช็คลิสต์ขึ้นหน้าเว็บจริง — มุมพนักงานหลังโอน

หลัง deploy (build **4.559+**) ที่ https://telltea-shop.web.app  
ใช้บัญชี**เจ้าของ**ก่อน แล้วสลับ **ดูแบบพนักงาน** — ไม่ต้องทักถามพนักงานรอบแรก

## ก่อนขึ้น

- [ ] GitHub Actions deploy `main` สำเร็จ
- [ ] เปิดไซต์แล้วเห็นเวอร์ชัน **4.559** (หรือสูงกว่า) ที่หน้าเกี่ยวกับ / อัปเดตแอป
- [ ] มีพนักงานอย่างน้อย 1 คนที่โอนรวมสิ้นเดือน+โบนัสไปแล้ว (หรือ pending พร้อมโอนรวม)

## เจ้าของ — ดูแบบพนักงาน (Phase E)

- [ ] จ่าย/โบนัส → ปุ่ม **ดูแบบพนักงาน** โชว์
- [ ] เลือกชื่อพนักงานที่เพิ่งได้เงิน → แบนเนอร์เขียว **กำลังดูแบบพนักงาน**
- [ ] ไม่เห็นปุ่มโอนรวม / สร้างเงินเดือน / ปิดเดือน / แก้เรทหัก
- [ ] แท็บสรุปโบนัส: การ์ด **ของฉัน** ของคนนั้น · ไม่มีตารางทั้งร้าน
- [ ] กด **กลับมุมร้าน** แล้วคิวร้านกลับมา

## หลังจ่ายแล้ว — การ์ดรอบล่าสุด (F)

- [ ] มุมพนักงาน (หรือดูแบบพนักงาน) → แท็บ **รอโอน**
- [ ] เห็นการ์ด **รอบล่าสุด · เข้าบัญชีคุณ** ยอดรวม + แตกสิ้นเดือน/โบนัส
- [ ] มีสลิปเปิดได้ (ถ้าแนบตอนโอน)
- [ ] ข้อความประมาณ “ไม่แจ้งแชทตอนโอน”
- [ ] ถ้าจ่ายครบ: รายการรอโอนว่าง แต่การ์ดรอบล่าสุดยังอยู่

## สรุปโอน + ประวัติ (G / I)

- [ ] แท็บ **ทั้งหมด**: แถวมีป้ายโอนรวม + โน้ต (ถ้ามี)
- [ ] แท็บ **ประวัติ**: มีตัวเลือกเดือน · บอกช่วงที่โหลด
- [ ] แถวเดือนมี meta กลาง/สิ้น/แยก ใต้คอลัมน์เงินเดือน
- [ ] แตะเดือนที่โอนรวม → เห็นบรรทัด **โอนครั้งเดียว ฿…**
- [ ] เข้าใจว่าแยกตาม**งวดงาน** ไม่ใช่วันเงินเข้า

## โยงหัก / หลักฐาน (H)

- [ ] จากการ์ดรอบล่าสุดกด **สรุปโบนัส + หลักฐานหัก** → ไปแท็บสรุปโบนัสงวดนั้น
- [ ] ถ้ามีหักร้าน: เห็นบรรทัด `ก่อนหัก − หัก = โอน`
- [ ] หลักฐานระวัง/ตัดอ่านได้อย่างเดียว (มุมพรีวิว)

## ช่วยโอนฝั่งร้าน (J)

- [ ] มุมร้าน → คิวรอโอนรวม → กด **โอนรวม**
- [ ] โมดัลโชว์บัญชี (ถ้าตั้งไว้) + ปุ่ม **คัดลอกบัญชี + ยอดโอน**
- [ ] วางในโน้ต/แอปธนาคารได้ครบชื่อ·บัญชี·ยอด

## พนักงานจริง (สั้น)

- [ ] ล็อกอินพนักงาน 1 คนที่เงินเข้าแล้ว
- [ ] แท็บรอโอนเห็นการ์ดรอบล่าสุดตรงกับเงินเข้า
- [ ] ประวัติเดือนนั้นสถานะครบแล้ว + สลิป
- [ ] ไม่เห็นยอดคนอื่น

## ถ้าผิดพลาด

| อาการ | ตรวจ |
|---|---|
| ไม่มีปุ่มดูแบบพนักงาน | ไม่ใช่เจ้าของ / ไม่มีสิทธิ์ payrollPay |
| การ์ดรอบล่าสุดไม่ขึ้น | ยังไม่มีแถว `paid` ของคนนั้นในช่วงที่โหลด |
| ไม่มีเลขบัญชีตอนคัดลอก | แท็บตั้งค่าจ่ายของพนักงานยังว่าง |
| ยอดโบนัสหักไม่ตรงบรรทัดอธิบาย | เลือกเดือนให้ตรงงวดบนการ์ด แล้วเปิดสรุปโบนัส |

จบเช็คลิสต์ = พร้อมให้พนักงานใช้เองโดยไม่ต้องไลน์แจ้งยอด

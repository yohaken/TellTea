# VAT — โครงสร้างตาราง (วิเคราะห์)

> อัปเดต: 2026-07-28 · หน้า `/vat-sales/` แท็บ **เดือน**

---

## คำตอบสั้น: แบ่ง **3 ตาราง**

| # | ตาราง | กลุ่ม | ความหมาย |
|---|--------|------|----------|
| **1** | **ภาษีขาย** | รายได้ | ยอดขาย → ฐานภาษี → ภาษีขาย (Output) |
| **2** | **ภาษีซื้อ** | หักได้ | บิล GP + วัตถุดิบ → ภาษีซื้อ (Input) |
| **3** | **สรุป** | ผลลัพธ์ | ภาษีขาย − ภาษีซื้อ = **สุทธิต้องนำส่ง** |

ถูกแล้ว: ตารางสรุป = นำผลรวมตาราง 1 มาหักด้วยผลรวมตาราง 2  
โครงวางคล้ายกัน: แถว **เดลิเวอรี่ / หน้าร้าน / รวม** · ข้อความแถวเดียว · compact slim · รายละเอียดครบไม่ย่อเกิน

---

## ทำไมแยก 3 ตาราง (ไม่รวมก้อนเดียว)

1. **คิดแบบสรรพากร:** Output กับ Input คนละฝั่ง — รวมคอลัมน์เดียวอ่านยาก  
2. **กลุ่มรายได้ vs หักได้** งานคนละอย่าง (กรอกยอดขาย ≠ กรอกบิลซื้อ)  
3. **สรุปสั้น** เห็นสุทธิทันที ไม่ต้องไล่คอลัมน์ยาว  
4. UI ยังจบในหน้าเดียว (1–2 แท็บ: เดือน / ปิด P&L)

---

## รายละเอียดตาราง

### 1) ภาษีขาย (รายได้)

- เดลิเวอรี่ `+` → ShopeeFood / Grab / LINE MAN  
- หน้าร้าน `+` → เงินโอน / เงินสด  
- คอลัมน์: ยอดขายรวม VAT · ฐานภาษี · เรทขาย (แตะแก้) · ภาษีขาย  
- เรทคนละเดือนได้ · ปิดงบแล้วล็อก  

### 2) ภาษีซื้อ (หักได้) — โครงแถวคล้ายตาราง 1

- แถวเดลิเวอรี่ / หน้าร้าน / รวม  
- คอลัมน์: GP % · ภาษีซื้อ GP · ยื่น % · ภาษีซื้อวัตถุดิบ · ภาษีซื้อรวม  
- ติ๊กประมาณ GP ได้ · play-safe ปัดลง/ยื่นหย่อน  

### 3) สรุป

| รายการ | ส่ง | ร้าน | รวม |
|--------|-----|------|-----|
| ภาษีขาย (Output) | … | … | … |
| หัก ภาษีซื้อ (Input) | … | … | … |
| **ภาษีสุทธิต้องนำส่ง** | … | … | … |

สูตร: `สุทธิ = Output − Input`

## UI กฎเหล็ก

- compact slim · full detail · text single row (`nowrap` + เลื่อนแนวนอนเมื่อจำเป็น)  
- ไม่ซ่อนคำสำคัญ (ภาษีขาย / ภาษีซื้อ / สุทธิต้องนำส่ง)  
- ไม่ใช้เศษคลุมเครือ — GP ระบุ **%**

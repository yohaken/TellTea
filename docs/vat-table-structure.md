## คำตอบสั้น: เลื่อนลงหน้าเดียว

| # | บล็อก | ความหมาย |
|---|--------|----------|
| **1** | **ภาษีขาย** | ยอดขาย → นำส่งจริง → ฐานภาษี → ภาษีขาย |
| **2** | **GP รายช่องทาง** | ยอดโอนหลัง → คชจ. GP (P&L) + ภาษีซื้อ GP (VAT) |
| **3** | **ภาษีซื้อ** | GP จากช่องทาง + วัตถุดิบจากบช. |
| — | **แถบสุทธิ** | ขาย − ซื้อ = สุทธิต้องนำส่ง (ไม่แยกตารางเต็ม) |
| **4** | **บช. สองสมุด** | COGS / SGA / สินทรัพย์ → หัก P&L |
| **5** | **ภ.ง.ด.** | รายได้สุทธิ − คชจ.บช. − ลดหย่อน |

ปุ่มท้ายหน้า: ร่าง · บันทึก · รายได้ทดลอง → P&L · ปิดงบจริง → ล็อก

## 1) ภาษีขาย (รายได้)

| คอลัมน์ | ความหมาย |
|---------|----------|
| ส่วน | เดลิเวอรี่ `+` / หน้าร้าน `+` |
| **รายได้หน้าร้าน / ยอดขายรวม** | ยอดรวม |
| **นำส่ง %** | หน้าร้าน default **90%** · เดลิเวอรี่ = 100% |
| **นำส่งจริง** | รายได้ × นำส่ง% — คิด VAT จากคอลัมน์นี้ |
| ฐานภาษี | ยอดก่อน VAT จากยอดนำส่งจริง |
| **เรทขาย %** | เช่น **7%** |
| ภาษีขาย | Output VAT |

---

## 2) GP รายช่องทาง → VAT + P&L

| คอลัมน์ | ความหมาย |
|---------|----------|
| รายได้ | จากตารางขายแยกช่องทาง |
| ยอดโอนหลัง | ใส่ของจริง |
| คชจ. GP | รายได้ − โอนหลัง → รวมหัก P&L |
| เรท % | คำนวณ · แถวรวม = เฉลี่ยถ่วงน้ำหนัก (ภาพรวม) |
| ภาษีซื้อ GP | จากคชจ. หรือใบกำกับ → Σ เข้าภาษีซื้อเดลิเวอรี่ |

---

## 3) ภาษีซื้อ (หักได้)

| คอลัมน์ | ความหมาย |
|---------|----------|
| ภาษีซื้อ GP | เดลิเวอรี่ = จากช่องทาง · หน้าร้านคีย์/ประมาณ |
| ยื่น % | play-safe เช่น 98% |
| วัตถุดิบ | จากบิลจริง (ติ๊ก「รวมเข้าระบบ」) |
| ภาษีซื้อรวม | Input รวมแถว |

## Chrome รอบตาราง (อย่าทำปุ่มใหญ่)

| ชิ้น | กฎ |
|------|-----|
| **โน้ต** | มุมขวาบน · ปุ่มเล็ก `+ โน้ต` |
| **บันทึก / ร่าง / ปิดงบ** | ปุ่ม **mini** ท้ายหน้าเดียว |
| **จำอัตโนมัติ** | localStorage ต่อเดือน · จุด「ยังไม่บันทึก」 |
| **ออกโดยไม่เซฟ** | `beforeunload` + confirm ตอนเปลี่ยนเดือน |
| **รอบตัดยอด** | `00:00 น. … → 23:59 น. …` — ไม่โชว์ timezone |
| **ตัวเลขไม่หาย** | soft sync · local สำรอง · เซฟร่าง Firestore อัตโนมัติ |
| **เดือน** | ตัวเลือก **เดือนไทย + พ.ศ.** |

รายละเอียดช่องว่างยื่นสรรพากร: [`vat-personal-pnl-gap.md`](./vat-personal-pnl-gap.md)

## UI กฎเหล็ก

- compact slim · full detail · text single row (`nowrap` + เลื่อนแนวนอนเมื่อจำเป็น)  
- ไม่ซ่อนคำสำคัญ (ภาษีขาย / ภาษีซื้อ / สุทธิต้องนำส่ง)  
- เรทขายเป็น **%** ไม่ใช่เศษ/ส่วนใน UI  
- หน้าร้านคิด VAT จาก **นำส่งจริง** เท่านั้น  
- หน้าเดือน = ยอดใช้จริงเลื่อนเดียว (ไม่แยกแท็บปิด P&L)  
- แท็บ **นำเข้า** (เฟสถัดไป) = ไฟล์/แถววัน — ดู [`vat-import-phases.md`](./vat-import-phases.md)

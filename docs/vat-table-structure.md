# VAT — โครงสร้างตาราง UI (เก็บไว้)

> อัปเดต: 2026-07-28 · หน้า `/vat-sales/` แท็บ **เดือน**  
> UI ตาราง compact ชุดนี้ถือเป็น baseline ที่ใช้ต่อ — อย่าพังโครง 3 ตาราง

---

## คำตอบสั้น: แบ่ง **3 ตาราง**

| # | ตาราง | กลุ่ม | ความหมาย |
|---|--------|------|----------|
| **1** | **ภาษีขาย** | รายได้ | ยอดขาย → นำส่งจริง → ฐานภาษี → ภาษีขาย (Output) |
| **2** | **ภาษีซื้อ** | หักได้ | บิล GP + วัตถุดิบ → ภาษีซื้อ (Input) |
| **3** | **สรุป** | ผลลัพธ์ | ภาษีขาย − ภาษีซื้อ = **สุทธิต้องนำส่ง** |

โครงแถว: **เดลิเวอรี่ / หน้าร้าน / รวม** · ข้อความแถวเดียว · slim · คอลัมน์ auto-size ไม่ตัดคำ

---

## 1) ภาษีขาย (รายได้)

| คอลัมน์ | ความหมาย |
|---------|----------|
| ส่วน | เดลิเวอรี่ `+` / หน้าร้าน `+` |
| **รายได้หน้าร้าน / ยอดขายรวม** | ยอดรวม (เดลิเวอรี่ = ยอดขายรวม VAT · หน้าร้าน = รายได้หน้าร้าน) |
| **นำส่ง %** | หน้าร้าน default **90%** แตะแก้ได้ · เดลิเวอรี่ = 100% |
| **นำส่งจริง** | รายได้ × นำส่ง% — **คอลัมน์นี้เท่านั้น** ที่นำไปคิด VAT |
| ฐานภาษี | ยอดก่อน VAT จากยอดนำส่งจริง |
| **เรทขาย %** | เช่น **7%** (= รวมในราคา 7÷107) แตะแก้ต่อเดือน |
| ภาษีขาย | Output VAT |

- เดลิเวอรี่ `+` → ShopeeFood / Grab / LINE MAN  
- หน้าร้าน `+` → เงินโอน / เงินสด  
- ปิดงบแล้วล็อกทั้งตาราง

---

## 2) ภาษีซื้อ (หักได้)

| คอลัมน์ | ความหมาย |
|---------|----------|
| GP % ของภาษีขาย | default ~33.33% · ติ๊กประมาณได้ |
| ภาษีซื้อ GP | จากประมาณหรือคีย์เอง |
| ยื่นภาษีซื้อ % | play-safe เช่น 98% |
| ภาษีซื้อวัตถุดิบ | จากบิลจริง |
| ภาษีซื้อรวม | Input รวมแถว |

## Chrome รอบตาราง (อย่าทำปุ่มใหญ่)

| ชิ้น | กฎ |
|------|-----|
| **โน้ต** | มุมขวาบนเหนือตาราง · ปุ่มเล็ก `+ โน้ต` · ขยาย textarea ได้ |
| **บันทึก / ร่าง** | ปุ่ม **mini** เล็กๆ พอมองเห็น — ไม่ใช้ primary ใหญ่ |
| **จำอัตโนมัติ** | คีย์แล้วเก็บ localStorage ต่อเดือน · มีจุดสถานะ «ยังไม่บันทึก» |
| **ออกโดยไม่เซฟ** | `beforeunload` + confirm ตอนเปลี่ยนเดือน (OK=ออก / Cancel=อยู่) |
| **รอบตัดยอด** | แสดงเฉพาะ `00:00 น. … → 23:59 น. …` — **ไม่โชว์** `Asia/Bangkok` ใน UI |

---

## UI กฎเหล็ก

- compact slim · full detail · text single row (`nowrap` + เลื่อนแนวนอนเมื่อจำเป็น)  
- ไม่ซ่อนคำสำคัญ (ภาษีขาย / ภาษีซื้อ / สุทธิต้องนำส่ง)  
- เรทขายเป็น **%** ไม่ใช่เศษ/ส่วนใน UI  
- หน้าร้านคิด VAT จาก **นำส่งจริง** เท่านั้น

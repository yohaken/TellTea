# เฟส · สิ้นเดือนโอนพร้อมโบนัส + หลักฐานระวัง/ตัด

เป้าหมายร้าน: **โอนครั้งเดียวต่อคน = เงินเดือนสิ้นเดือน + โบนัส** (หลังหักนิ่ง)  
คิวยังแยกชนิดในระบบ (บัญชีชัด + พนักงานเห็นรายละเอียด) — รวมชั้นโอน

## วิธีใช้ปิดเดือน

1. เคลียร์เบิก / หักค้าง → **สร้างเงินเดือน**
2. หักโบนัสให้นิ่ง → **สร้างโบนัส**
3. ที่แท็บ **รอโอน** กด **โอนรวม** (แถวสิ้นเดือน) → แนบสลิปยอดรวมครั้งเดียว  
   - ระบบ mark จ่ายทั้งแถวสิ้นเดือน + โบนัส  
   - ลงบช.แยก 2 แถว สลิปชุดเดียวกัน  
   - พนักงานยังเห็น 2 รายการ (ยอดสิ้นเดือน / ยอดโบนัส) ในคิวของตัวเอง
4. **อย่า** กดโอนเงินเดือนอย่างเดียวก่อน ถ้าตั้งใจรวมโบนัส — พอจ่ายสิ้นเดือนไปแล้ว จะเหลือแต่โบนัสให้โอนแยก

กลางเดือน (`salary_mid`) / จ่ายแยก ไม่เข้าโอนรวม

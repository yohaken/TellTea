# เฟส · สิ้นเดือนโอนพร้อมโบนัส + หลักฐานระวัง/ตัด

เป้าหมายร้าน: **โอนครั้งเดียวต่อคน = เงินเดือนสิ้นเดือน + โบนัส** (หลังหักนิ่ง)  
คิวยังแยกชนิดในระบบ (บัญชีชัด) — รวมชั้นโอน

## ของเดิมที่เคลียร์ก่อนระบบใหม่

- [ ] One-shot ยกเลิกคิว `salary_mid` / `salary_month_end` ที่ `pending` (`scripts/void-pending-group-salary.mjs`)
- [ ] เจ้าของกด **สร้างเงินเดือน** ใหม่หลังขึ้น live
- [ ] โบนัส: สร้างเมื่อหักนิ่ง (แยกปุ่ม)

## Phase A — คิว + สร้าง (ฐาน) ✅ / กำลังใช้

- [x] แยกสร้างเงินเดือน / โบนัส
- [x] หักเบิก · บันทึกเบิกวัน+สลิป+บช.
- [x] regenerate อัปเดต pending + บังคับรวมคนมีเบิกค้าง
- [ ] หลัง one-shot void → สร้างเงินเดือนใหม่ทั้งร้าน

## Phase B — โอนรวมสิ้นเดือน + โบนัส

- [ ] จัดกลุ่มคิวต่อคนในเดือน: `salary_month_end` + `bonus` ที่ pending
- [ ] UI: แถวสรุป «ชื่อ · สิ้นเดือน ฿x + โบนัส ฿y = โอน ฿z»
- [ ] ปุ่ม **โอนรวม** → แนบสลิปเดียว · mark จ่ายทั้ง 2 แถว · ลงบช.แยกตามชนิด (หรือ 2 แถวบช. สลิปเดียวกัน)
- [ ] ยังโอนแยกรายการได้ถ้าต้อง
- [ ] กลางเดือน (`salary_mid`) ไม่รวมในโอนรวม

## Phase C — หลักฐาน 2 กอง + บังคับดู

- [ ] กอง **ระวัง** (ไม่ตัดโบนัส) — รูป+โน้ตต่องวด
- [ ] กอง **ตัด** (หักโบนัส) — ต่อจากหลักฐานเดิม
- [ ] พนักงาน: สไลด์ดูบังคับ **ระวัง → ตัด** ถึงจะถือว่าดูครบ
- [ ] เจ้าของ: แนบแยกกอง · เรียงลำดับในแต่ละกอง

## Phase D — ขัดเกลา

- [ ] ประวัติโอนรวม / สลิปร่วม
- [ ] เช็คลิสต์ปิดเดือน: หักนิ่ง → สร้างโบนัส → โอนรวม
- [ ] (ถ้าต้องการ) มุมมองพนักงานเห็นยอดโอนรวมของตัวเอง

## นอกขอบ

- ไม่รวมแถวเงินเดือน+โบนัสเป็น doc เดียวใน Firestore (ยุ่งเบิก/ยกเลิก)
- ไม่บังคับโอนรวมกลางเดือน

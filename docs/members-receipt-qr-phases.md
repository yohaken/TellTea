# สมาชิกจาก QR บนสลิป — เฟสทดลองก่อนขายจริง

ไอเดีย: ไม่มีจอทัชให้ลูกค้า · พนักงานขายปกติ · **สลิปเงินสดมี QR** → ลูกค้าสแกนเองสมัคร/สะสมแต้ม  
สูตรแต้มใช้ **ทุกกี่บาท = 1 แต้ม** ชุดเดียวกับระบบสมาชิก · บันทึกว่าแต้มมาจากบิล/QR ใบไหน

## หลักการช่วงแรก (สำคัญ)

ช่วงนี้ = **ทดลองในมุมคุณเอง** · คาดว่ามีบั๊ก/ปัญหาหลังลงของ · **ยังไม่ขายจริงให้ลูกค้า** และ **ไม่กระทบยอดหน้าร้าน**

| ข้อ | ความหมาย |
|-----|----------|
| **ทดลองโดยเจ้าของเท่านั้น** | คุณสแกน/สมัคร/เคลมเองก่อน — ยังไม่เปิดให้ลูกค้าจริง |
| **ไม่กระทบยอดหน้าร้าน** | ไม่แก้ path ปิดบิล/เงินสด/ปิดกะของเครื่องที่ใช้อยู่ |
| **ปิดเป็นค่าเริ่ม** | ธงทดลองต้องเปิดเอง · ค่าเริ่ม = ปิด |
| **ไม่บังคับ OTA APK** | จนกว่าทดลองเซิร์ฟเวอร์+หน้าเว็บนิ่งแล้วค่อยพิมพ์ QR บนสลิปจริง |
| **คาดว่ามีบั๊ก** | เฟส R0–R2 คือสนามทดลอง · คุณสแกนทุกเคส · พบแล้วแก้ก่อน R3 |
| **ห้ามข้ามไป R4** | เปิดขายจริงเฉพาะเมื่อคุณยืนยันหลังทดลองเอง — ไม่เปิดอัตโนมัติ |

## โฟลว์เป้าหมาย (เมื่อครบ)

```text
ปิดบิล (ขายปกติ)
  → สร้าง claimToken ผูกบิลนั้น (ครั้งเดียว)
  → สลิปมี QR → /claim/?s=<saleId>&t=<token>
        ↓ สแกน
  ├─ ยังไม่สมาชิก → เบอร์ + OTP + PDPA เล็กน้อย → สมัคร → เคลมแต้มบิลนี้
  └─ เป็นสมาชิกแล้ว → OTP ยืนยัน (ถ้ายังไม่ล็อกอิน) → เคลมแต้มบิลนี้ทันที
```

วันหลังซื้อ → สลิปใหม่ → QR ใหม่ → เคลมเข้าบัญชีเดิม

## สรุปเฟส

| เฟส | โหมด | ส่งมอบ | กระทบหน้าร้าน? |
|-----|------|--------|----------------|
| **R0** | ✅ ทดลอง | สเปก + ธง `receiptClaimEnabled` / อัตรา 1% ในตั้งค่าหลังร้าน | ไม่ |
| **R1** | ✅ โค้ดพร้อมทดลอง | หน้า `/claim` + OTP + PDPA + เคลมแต้มจากบิลทดสอบ | ไม่ |
| **R2** | ✅ โค้ดพร้อมทดลอง | สร้าง claim จากบิลในหลังร้าน (หรือบิลทดสอบ) · คุณสแกนเอง | ไม่ |
| **R3** | ทดลองจำกัด | nPos พิมพ์ QR บนสลิป — เปิดเฉพาะเมื่อธงทดลองเปิด · ยังไม่โฆษณาลูกค้า | พิมพ์สลิปเท่านั้น ไม่เปลี่ยนยอด |
| **R4** | ขายจริง | เปิดให้ลูกค้า · ข้อความบนสลิป · มอนิเตอร์บั๊ก/โกง | ใช่ — หลังคุณยืนยันแล้วเท่านั้น |

## R0 — โครงและธงทดลอง

- [x] เอกสารนี้เป็นแหล่งความจริงของเฟส QR สลิป
- [x] `memberSettings`: `receiptClaimEnabled` (default **false**) · สูตรแต้มใช้ `bahtPerPoint` ชุดเดียว
- [x] UI ตั้งค่าที่ `/members` แท็บตั้งค่า — ป้ายชัดว่า **โหมดทดลอง · ยังไม่ขายจริง**
- [x] ไม่เรียกพิมพ์ QR จากเครื่องขาย

**เกณฑ์จบ:** เจ้าของเปิด/ปิดธงได้ · ค่าเริ่มปิด

## R1 — หน้าเคลม + สมัครด้วย OTP (ทดลอง)

- [x] หน้า `/claim/?s=&t=` (แยกจาก staff auth)
- [x] สมัคร/เคลม: **Google ปุ่มใหญ่** · เบอร์+OTP เป็นทางรอง · ผูกเบอร์ครั้งแรกถ้ายังไม่มีสมาชิก
- [x] หลังเคลม: popup แสดง +แต้ม / รวม · QR ใบนั้นจบ
- [x] ดูแต้มทีหลัง: `/me` ต้องเข้าสู่ระบบ (Google หรือ OTP) — ไม่ใส่เบอร์เปล่าแล้วดูของคนอื่น
- [x] เคลมแต้ม: ledger `earn_receipt_claim` + `saleId` + ช่องทาง `receipt_qr`
- [x] โหมดทดลอง: รับเฉพาะเมื่อ `receiptClaimEnabled`

**เกณฑ์จบ:** คุณสมัคร+เคลมจากลิงก์ทดสอบบนมือถือได้โดยไม่ผ่านเครื่องขาย

## R2 — สร้าง QR/ลิงก์เคลมจากหลังร้าน (ยังไม่พิมพ์ที่เคาน์เตอร์)

- [x] หลังร้าน: เลือกบิล (หรือสร้างบิลทดสอบ) → แสดง QR + คัดออกลิงก์
- [x] Server ออก `claimToken` ผูก `posSales/{saleId}` · อายุเช่น 7–30 วัน
- [x] หลังเคลม: สแกน QR เดิม → หน้า «แต้มบิลนี้ใช้แล้ว» + ปุ่มไป `/me`
- [x] หลังร้านเทส: ปุ่ม **แสดง QR / QR เดิม** (จำโทเคนเดิมแม้เคลมแล้ว) + **โทเคนใหม่ (เทส)** จาก saleId เดิม
- [ ] คุณสแกนด้วยมือถือจริง วนเคส: สมาชิกใหม่ / สมาชิกเดิม / เคลมซ้ำ / โทเคนหมดอายุ
- [ ] หลังร้านเห็น ledger ว่าแต้มมาจากบิลไหน

**เกณฑ์จบ:** คุณทดลองครบเคสหลักด้วยตัวเอง · ยังไม่แตะ APK

## R3 — พิมพ์ QR บนสลิป (รวมในรอบ P5 — A1)

นโยบายล็อก: ดู [members-round-phases.md](./members-round-phases.md)

- [x] nPos พิมพ์ QR ท้ายสลิปเมื่อธงพิมพ์เปิด — **ทุกใบ** (ไม่ต้องมีสมาชิกก่อน)
- [x] สุทธิ 0 / แต้มสะสม 0 → **ยังพิมพ์ QR** · สแกนแล้วไปหน้าสมาชิก ไม่ตัน
- [x] แต้มจากเคลม = จากยอดชำระ (`total`) หลังหักแลกแต้ม
- [x] QR ขนาดกลาง · คำเชิญสั้น «สแกนสะสมแต้ม»
- [x] ค่าเริ่มธงปิดบนเครื่องขายจริงจนกว่าเกต P6
- [x] ปิดบิล path ไม่เปลี่ยนยอด/เงินทอนเมื่อธงปิด
- [ ] เทสสลิปจริงบนเครื่องทดสอบก่อนเปิดร้าน

**เกณฑ์จบ:** สลิปมี/ไม่มีแต้มสแกนได้ตามนโยบาย · ยอดขาย/ปิดกะไม่เพี้ยน · รวมส่งมอบใน **P5** (APK 139)

## R4 — เปิดขายจริงให้ลูกค้า (ทำเมื่อคุณโอเคเท่านั้น)

**ยังไม่เริ่มในรอบนี้** — รอหลัง R0–R3 ผ่านการทดลองของคุณเอง

- [ ] เอาป้าย «ทดลอง» ออก (หรือแยกธง `receiptClaimPublic`)
- [ ] พนักงานบอกสั้นๆ ได้ถ้าต้องการ — ไม่บังคับคีย์เบอร์ที่เคาน์เตอร์
- [ ] มอนิเตอร์: เคลมซ้ำ, OTP ล้ม, สลิป void, ยอดแต้มผิด
- [ ] คู่มือสั้นสำหรับพนักงาน 1 หน้า

**เกณฑ์จบ:** เปิดได้โดยไม่กระทบยอด · มีทางปิดธงฉุกเฉินกลับเป็นสลิปเดิม

## สิ่งที่จงใจยังไม่ทำในช่วงทดลอง

- ไม่บังคับพนักงานคีย์เบอร์ตอนขาย  
- ไม่มีจอลูกค้าให้คีย์  
- ไม่ผูกแต้มอัตโนมัติตอนปิดบิลโดยไม่สแกน (ช่วงนี้แต้มเข้าเมื่อเคลมจาก QR)  
- ไม่เปิด QR สมัครสาธารณะแบบไม่มีบิล (`/join` แยกเรื่อง — ใช้เมื่อพร้อม)

## ผูกกับของที่มีอยู่

| ของเดิม | ใช้ต่อ |
|--------|--------|
| `/members` เจ้าของ | ตั้งค่าธงทดลอง · ดูสมาชิก/ledger |
| `memberLedger` + `saleId` | บอกว่าแต้มมาจากบิลไหน |
| `publicMemberSignup` / `/join` | แนวทางหน้าสาธารณะ — R1 จะเป็น `/claim` ผูกบิล |
| nPos พิมพ์สลิป | แตะครั้งแรกที่ R3 เท่านั้น และมีธงปิด |

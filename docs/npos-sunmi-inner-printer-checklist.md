# nPos — SUNMI InnerPrinter (built-in)

อัปเดต: **1.14.107** · vc **119** (InnerPrinter path since 1.14.68+)

## ปัญหาหน้างาน
Wongnai พิมพ์ไทย/ลิ้นชักบน **SUNMI D2s_PLUS** ได้ · nPos เดิมส่ง ESC/POS TIS-620 ผ่าน `sendRAWData` → ตัวอักษรเพี้ยนเป็นจีน  
พนักงานไม่ควรต้องเลือกเครื่องพิมพ์เอง

## ใช้ปริ้นร่วม LINE MAN / แอปเดลิเวอรี (vc 144+)
เครื่องมี InnerPrinter **ตัวเดียว** · nPos ต้องไม่ยึด AIDL ค้างทั้งเซสชัน

| ข้อ | พฤติกรรม |
|-----|----------|
| Bind | เฉพาะตอนพิมพ์/เปิดลิ้นชัก |
| หลังจบงาน | `printerInit` + รีเซ็ตฟอนต์/จัดแนว · แล้ว `unBindService` |
| ผล | เปิด nPos ก่อนหรืออัปเดต OTA แล้ว LINE MAN ยังพิมพ์ออเดอร์ต่อได้ |

ทดสอบคน: เปิด nPos → ขาย 1 บิล → สลับ LINE MAN → ออเดอร์ทดสอบต้องออกกระดาษ

## ทำแล้ว (1.14.68+)
| ข้อ | รายละเอียด |
|-----|------------|
| SDK | `com.sunmi:printerlibrary:1.0.24` |
| Auto-select | เปิดแอปบน Sunmi → เลือก InnerPrinter ให้อัตโนมัติ (ไม่ทับ USB/BT/LAN ที่พร้อมแล้ว) |
| พิมพ์ไทย | ถอด ESC/POS → `printText` (UTF) เหมือนแอปสต็อก/Wongnai |
| ตัวหนา | **1.14.85** — คง ESC E เป็น marker → `printText` สลับกับ `sendRAWData(ESC E)` (ชื่อเมนูหนา · option บาง) |
| ลิ้นชัก | `openDrawer` |
| Fallback | ถ้าแปลงข้อความไม่ได้ ค่อย `sendRAWData` |
| แป้นเงินสด | **1.14.69** — คีย์หดตามจอ + การ์ด fit-to-window |
| สถานะ BO | **1.14.71** — พิมพ์/ลิ้นชักสำเร็จ → ตารางขึ้น `พ✓ ล✓` |

# nPos — ประวัติการขาย + ตัวอย่างบิล BO compact

อัปเดต: **1.14.46** · `APP_BUILD` 304 · `POS_BUILD` 99 · vc **69**

## สcope

| ทำ | หมายเหตุ |
|----|----------|
| Custom ช่วงวันที่ (native) | ชิป «ระบุวัน» + จาก–ถึง |
| BO รายงาน | กระโดดวันด้วย `<input type="date">` · หมวดสรุปพับ · บิล compact เต็มคอลัมน์ |
| BO `?tab=manage` | หมวดพับตอนเปิด · ตัวอย่างสลิปเต็มพื้นที่ · ตัวอักษรเทคนิคย่อ |
| ค้นหาลูกค้า/เบอร์ | ค้นหาได้ถ้ามีบนบิล · **ยังไม่เก็บตอนขาย** (ไม่กระทบเคาน์เตอร์) |
| Refund | = กรอง **ทำลาย/void** (ไม่มีเส้นเงินคืนแยก) |
| VAT / Service | แสดงบนสลิปถ้ามีค่า · ตัวอย่างพรีวิว · **ไม่คิดในไหลขาย** |

## นอกสcope (ยังล็อก)

- ฟอร์มเก็บชื่อ/เบอร์ลูกค้าตอนจ่าย · บัตรเครดิต · PIN · SMS/Email · คิด VAT จริงบนเคาน์เตอร์

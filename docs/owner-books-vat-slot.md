## ช่อง VAT ในแต่ละรายการเงินออก

| ฟิลด์ | ความหมาย |
|------|----------|
| **มีใบกำกับภาษี** (`hasVat`) | เก็บยอดภาษีซื้อจากบิล |
| **ภาษีซื้อ** (`vatInput`) | ยอด VAT จากบิล (AI อ่านก่อน) |
| **เลขที่ใบกำกับ** (`vatInvoiceNo`) | ถ้ามี — คีย์เก็บ |
| **vatSource** | `ai` · `manual` · `propose` |
| **vatVerified** | ติ๊กตรวจตรงบิลแล้ว |
| **รวมเข้าระบบ** (`vatClaim`) | ติ๊กที่ VAT เดือน (+) เมื่อหักได้จริง |

ใช้กับบิลเช่น **แม็คโคร · ท็อปเวิลด์ · ท็อปส์ · ท็อปแวลู · บิ๊กซี · โลตัส**  
ลำดับ AI→ตรวจ→กรอกเอง: [`books-vat-ai-verify.md`](./books-vat-ai-verify.md)

---

## ดึงเข้า VAT เดือน

แท็บ **VAT เดือน** → **`+` รายการจากสองบช.** → ติ๊ก **รวมเข้าระบบ** → **ดึงภาษีซื้อจากสองบช.**  
= รวม `vatInput` ของรายการที่ `vatClaim` → ช่องภาษีซื้อวัตถุดิบหน้าร้าน  
แตะแถวเปิดมุมมองเหมือนบช. เพื่อตรวจก่อนติ๊ก

# เฟส · มุมพนักงานชัดหลังโอน + ดูแบบพนักงาน

ต่อจาก `payroll-month-end-combined-phases.md` (A–C โอนรวม + หลักฐานระวัง/ตัด เสร็จแล้ว)

เป้าหมาย: หลังโอนเงินเดือน+โบนัส **พนักงานเข้าใจยอดเข้าบัญชีตัวเอง** โดยไม่พึ่งแชท  
เจ้าของต้อง **สลับดูแบบพนักงาน** ได้จริง — ไม่เดาจากคิวร้าน

นอกขอบ (ยังไม่ทำในชุดนี้)
- แจ้งแชท / LINE ตอนจ่าย
- Deep link เปิดแอปกสิกรกรอกฟอร์มโอนอัตโนมัติ

---

## Phase E — ดูแบบพนักงาน (**ต้องมี**) — โค้ดแล้ว · รอตรวจ live

เจ้าของ (หรือคนมีสิทธิ์ `payrollPay`) สลับ UI ให้เหมือนพนักงานคนที่เลือก

- [x] ปุ่ม **ดูแบบพนักงาน** + เลือกชื่อ
- [x] แบนเนอร์ชัด: กำลังดูแบบใคร · กลับมุมร้าน
- [x] ซ่อนคิวทั้งร้าน / โอนรวม / ปิดเดือน / แก้เรท·หัก / อัปหลักฐาน
- [x] โชว์การ์ดโบนัสของคนนั้น · คิว/ประวัติ/เงินเดือนฉัน เฉพาะคนนั้น · หลักฐานระวัง/ตัดแบบอ่านอย่างเดียว
- [ ] ตรวจบนเครื่องจริงหลัง deploy (เจ้าของสลับ 2–3 คน)

สิทธิ์จริงไม่ถูกถอด — เป็นโหมดดู UI อย่างเดียว ไม่เขียนทับเป็นพนักงาน

---

## Phase F — หลังจ่ายแล้วไม่หายจากสายตา

ปัญหา: แท็บ **รอโอน** ว่างหลัง mark จ่าย → พนักงานคิดว่าไม่มีอะไร

- [ ] การ์ด **รอบล่าสุดที่โอนเข้าบัญชีคุณ** บนแท็บรอโอน (เมื่อไม่มี pending)
  - ยอดรวมครั้งโอน (โอนรวมถ้ามี `combinedPayId`)
  - แตก: สิ้นเดือน / โบนัส / หักเบิก
  - ลิงก์สลิป + ไปประวัติเดือนนั้น
- [ ] ถ้ายังมี pending อื่น (กลางเดือนฯ) — คิวยังโชว์ปกติ การ์ดรอบล่าสุดอยู่ด้านบนหรือใต้คิวสั้นๆ
- [ ] ป้ายสั้นๆ ว่าไม่แจ้งแชท — ดูยอดที่นี่

---

## Phase G — ใบสรุปโอนในประวัติ / ตารางจ่าย

- [ ] ในประวัติ: แถวโอนรวมโชว์ **โอนครั้งเดียว ฿T** ชัด (ไม่ต้องอ่าน note ยาว)
- [ ] แท็บจ่าย (มุมพนักงาน · ทั้งหมด): โชว์ note สั้นของรอบโอนรวม
- [ ] สลิปร่วมของคู่สิ้นเดือน+โบนัส เปิดชุดเดียวกันทั้งสองแถว (พฤติกรรมเดิมคงไว้ ตรวจว่าเข้าใจง่าย)

---

## Phase H — โยงหักโบนัส / หลักฐาน กับยอดโอน

ตอนนี้สูตรโบนัสอยู่แท็บสรุป · หลักฐานระวัง/ตัดอยู่บล็อกแยก · ยอดโอนอยู่ประวัติ

- [ ] จากรอบโอนล่าสุด / รายละเอียดเดือน: ลิงก์ไป **สรุปโบนัสของฉัน** งวดนั้น + **หลักฐานระวัง/ตัด**
- [ ] บรรทัดสรุปหนึ่งบรรทัดใต้ยอดโบนัสที่โอน:  
  `โบนัสก่อนหัก ฿… − หักร้าน ฿… (x%) = โอน ฿…`  
  (ใช้ยอดจากแถวโบนัส / snapshot ปิดเดือน — ไม่สร้างสูตรใหม่)
- [ ] ไม่ต้องโชวยอดคนอื่น

---

## Phase I — ขัดเกลาตารางประวัติรายเดือน

พนักงานใช้ประวัติเป็นตารางรายได้ทีละงวด (`periodMonth`) อยู่แล้ว — ปรับให้อ่านง่ายขึ้น

- [ ] สรุปแถวเดือนแยก **กลางเดือน / สิ้นเดือน / จ่ายแยก** (ไม่รวมก้อนเดียวในคอลัมน์เงินเดือนอย่างเดียว — หรือใส่ meta ใต้ยอด)
- [ ] แท็บประวัติมีตัวบอกช่วงที่โหลด / เลือกเดือนอ้างอิงได้เอง (ไม่ผูกเงียบกับแท็บอื่น)
- [ ] คำอธิบายสั้น: แยกตาม**งวดงาน** ไม่ใช่วันเงินเข้าบัญชี

---

## Phase J — (ทางเลือก) ช่วยเจ้าของตอนกดโอนรวม

ไม่ใช่ deep link ธนาคาร — ช่วยลดพลาดตอนโอนมือ

- [ ] ตอนกดโอนรวม: คัดลอกเลขบัญชี + ยอดรวม + ชื่อ
- [ ] แสดงสรุปโอนก่อนแนบสลิป (มีอยู่แล้วบางส่วน — ตรวจให้ครบ)
- [ ] ทีหลังค่อยพิจารณา PromptPay QR ถ้าร้านเก็บ PromptPay พนักงาน

---

## ลำดับทำ

1. **E** ดูแบบพนักงาน ← ต้องมีก่อน ใช้ตรวจทุกเฟสหลังจากนี้  
2. **F** การ์ดรอบล่าสุด ← แก้ pain จุดเงินเข้าแล้วเปิดแอป  
3. **G + H** สรุปโอน + โยงหัก/หลักฐาน  
4. **I** ขัดเกลาประวัติ  
5. **J** ช่วยโอนฝั่งเจ้าของ (ถ้ายังต้องการ)

ตรวจรับ: เจ้าของเปิด **ดูแบบพนักงาน** หลังโอนรวมจริง แล้วยืนยันว่าพนักงานเห็นยอด/สลิป/หัก เข้าใจโดยไม่ต้องทักแชท

## Phase F — หลังจ่ายแล้วไม่หายจากสายตา ✅

- [x] การ์ด **รอบล่าสุดที่โอนเข้าบัญชีคุณ** บนแท็บรอโอน (มุมพนักงาน)

- [x] ถ้ายังมี pending — คิวยังโชว์ การ์ดอยู่ด้านบน
- [x] ป้ายสั้นๆ ว่าไม่แจ้งแชท — ดูยอดที่นี่
- [x] empty state รอโอนชี้ไปการ์ด/ประวัติ

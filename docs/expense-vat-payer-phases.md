## E0 — สเปกฟิลด์ (ต่อแถว)

| ฟิลด์ | ค่า | หมายเหตุ |
|------|-----|----------|
| `vatMode` | `unknown` / `none` / `inclusive` | ไม่แน่ใจ · ไม่มี VAT · ยอดรวมมี VAT |
| `vatBase` | number | ฐานภาษี |
| `vatInput` | number | VAT ซื้อ (ขอคืน) |
| `taxInvoiceNo` | string | เลขที่ใบกำกับ (ว่างได้) |
| `payer` | `shop` / `owner` / `staff` / `other` / `""` | ผู้จ่าย |
| `invoiceName` | string | ใบกำกับออกในนาม |
| `invoiceNameOk` | `unknown` / `ok` / `mismatch` / `no_invoice` | ใช้ขอคืนได้ไหม |

สูตรเมื่อ `inclusive`: ใช้ `computeVatFromGross(amountOut)` (7/107) — แก้มือได้

## E1 — แจ้งบิล + บช.เจ้าของ

### ทำในโค้ด

1. เก็บฟิลด์บน `billNotices` + `ownerBooks`
2. ฟอร์มเพิ่ม/แก้: กล่อง **VAT / ผู้จ่าย** หุบเป็นค่าเริ่มต้น
3. `acceptBillNotice` คัดลอกฟิลด์ไป บช.เจ้าของ
4. สรุปแจ้งบิล (กล่องวิเคราะห์) หุบเป็นค่าเริ่มต้นเช่นกัน

### เช็ค E1

- [x] โค้ด: ฟิลด์ + ฟอร์มกล่องหุบ + accept คัดลอก
- [ ] พนักงานเพิ่มแจ้งบิลค่าไฟ · เปิดกล่องใส่ VAT/ผู้จ่าย · บันทึกได้
- [ ] ไม่เปิดกล่องก็บันทึกได้ (`vatMode=unknown`)
- [ ] เจ้าของรับบิล → แถว บช.เจ้าของ มี VAT/ผู้จ่าย ตามที่เสนอ
- [ ] แก้ใน บช.เจ้าของ ผ่านกล่องหุบได้
- [ ] แถวตารางไม่ยืดสูงเพราะกล่องฟอร์ม

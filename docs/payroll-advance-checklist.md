# เช็คลิสต์ · เบิกล่วงหน้า → หักเงินเดือน

เคสตัวอย่าง: **แป๋ม** เบิกเงินเดือนวันที่ 28 → งวดสิ้นเดือน (50%) ต้องหักเบิกก่อนโอน

## Flow มาตรฐาน (ใช้ทุกครั้งที่มีเบิก)

1. เปิด `/bonus/` → แท็บ **รอโอน** · เลือกเดือนอ้างอิงให้ถูก (เช่น ก.ค. สำหรับสิ้นเดือน ก.ค.)
2. กด **บันทึกเบิก**
   - เลือกพนักงาน
   - ใส่วันที่เบิกจริง
   - ใส่ยอด
   - แนบสลิป (ถ้ามี)
   - ติ๊กยกเลิกคิวรอโอนของคนนี้ถ้ามีคิวเก่าที่ยังไม่หักเบิก
3. ยืนยัน → ระบบ
   - เพิ่ม **เบิกค้าง**
   - ลง **บช.เจ้าของ** (sga · เบิกล่วงหน้า) พร้อมวันที่ + สลิป
   - ยกเลิกคิวที่ติ๊กไว้ (ถ้ามี)
4. กด **สร้างเงินเดือน** → คิวในแท็บ **รอโอน** หักเบิกอัตโนมัติ  
   (สร้างใหม่ / กู้คืนจากยกเลิก / **อัปเดตคิว pending เดิมให้หักเบิก** — ไม่ต้องยกเลิกเองก็ได้)
5. โอน/เคลียร์ตามคิว · ตอนจ่ายจะตัดเบิกค้าง  
6. ถ้ายังไม่ขึ้นชื่อ: ดูแท็บ **รอโอน** (อย่าค้างที่ยกเลิก) · ตรวจว่าไม่ได้ติ๊ก **ข้ามรอบกลุ่ม** · มีเงินเดือนในตั้งค่า

## อย่าทำ

| ผิด | ถูก |
|-----|-----|
| แก้ช่อง「เบิกค้าง」ในตั้งค่าอย่างเดียวเมื่อเพิ่งจ่ายเงินจริง | ใช้「บันทึกเบิก」ให้ลงบช.+สลิป |
| สร้างเงินเดือนไปแล้วค่อยใส่เบิก แล้วกดสร้างซ้ำโดยไม่อยกเลิก | ยกเลิกคิวก่อน (หรือติ๊กในฟอร์มเบิก) แล้วสร้างใหม่ |
| คาดว่าแถว pending จะอัปเดตหักเบิกเอง | ระบบทับเฉพาะแถวที่ **void** หรือยังไม่มี |

## จ่ายแยก vs เบิก

- **บันทึกเบิก** = จ่ายเงินก่อนรอบ · หักจากงวดกลุ่มถัดไป · ลงบช.ทันที
- **จ่ายแยก** = สร้างคิวยอดกำหนดเอง (พนักงานใหม่/นอกวรรอบ) · ยังไม่ใช่การเบิกหักงวด

## ตรวจหลังทำ (เคสแป๋ม)

- [ ] บช.เจ้าของมีแถว「เบิกล่วงหน้า — แป๋ม」วัน 28 + สลิป
- [ ] ตั้งค่า/รายชื่อ: เบิกค้างของแป๋ม = ยอดที่เบิก (จนกว่าจะจ่ายคิวหัก)
- [ ] คิวสิ้นเดือนของแป๋ม: มีข้อความหักเบิก · ยอดโอนลดลงหรือ 0
- [ ] คนอื่นในรอบยังได้ 50% ปกติ
- [ ] พนักงานทั่วไปไม่เห็นยอดคนอื่น

## ช่องตั้งค่า「เบิกค้าง」

ใช้แก้ยอดค้างเก่าที่ไม่ได้ผ่าน「บันทึกเบิก」(เช่น ยอดยกมา) — **ไม่ลงสมุดซ้ำ**

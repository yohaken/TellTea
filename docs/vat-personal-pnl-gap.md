# กำไรขาดทุนง่าย · บุคคลธรรมดา — ของที่มี / ที่เติมแล้ว

> หน้า `/vat-sales/` แท็บ **ปิด P&L** · อัปเดต 2026-07-29

---

## ตารางรายได้แยก → P&L (สำคัญ)

| ขั้น | รายการ | ที่มา |
|------|--------|------|
| 1 | รายได้เดลิเวอรี่ | VAT ตาราง 1 · ฐาน/รวม ตามโหมด |
| 2 | รายได้หน้าร้าน | VAT ตาราง 1 |
| 3 | รวมก่อนหัก | 1+2 |
| 4 | **− หัก GP ก้อนเดลิเวอรี่** | ประมาณจากภาษีซื้อ GP → ต้นทุนก่อน VAT · **แก้ได้** |
| 5 | **= รายได้สุทธิ → P&L** | ใส่ `monthlyIncome` |

เดลิเวอรี่มียอดก้อนแพลตฟอร์ม — **ต้องหัก GP ก้อนก่อน** ถึงจะเป็นรายได้บุคคล · หน้าร้านไม่หักแถวนี้

---

## ภาษีเงินได้บุคคล (ภ.ง.ด.)

| รายการ | สถานะ | หมายเหตุ |
|--------|------|----------|
| ค่าลดหย่อนผู้มีเงินได้ | **มี** | default **60,000** · ดึงจาก `meta/personalTaxSettings` · แก้ได้ |
| ค่าลดหย่อนอื่น | **มี** | แก้เองได้ |
| ขั้นบันได | **มี** | ตามกฎหมาย (0–35%) แสดงในตาราง |
| สรุปรายปี | **มี** | ปุ่มดึงสรุปปีจาก P&L สองบช. |
| ส่งออกยื่น | **มี** | Excel ภ.ง.ด. |

---

## สูตร

```
รายได้เดลิเวอรี่ + รายได้หน้าร้าน − GP ก้อนเดลิเวอรี่
= รายได้สุทธิเดือน → P&L

รายได้สุทธิ − ค่าใช้จ่ายบช.พนง. − ค่าใช้จ่ายบช.เจ้าของ
= กำไรเดือน

รวมกำไรปี − ค่าลดหย่อนผู้มีเงินได้ − ลดหย่อนอื่น
= เงินได้สุทธิ → คิดขั้นบันได = ภาษีประมาณ
```

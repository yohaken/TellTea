# กำไรขาดทุนง่าย · บุคคลธรรมดา — ของที่มี / ที่ยังขาด

> หน้า `/vat-sales/` · อัปเดต 2026-07-29  
> เป้า: ประมาณกำไรเดือน + เตรียมนำส่งรายได้บุคคลสรรพากร (ไม่ใช่บัญชีบริษัท)

---

## ตารางสรุป (จากระบบที่มี)

| รายการ | แหล่งในระบบ | สถานะ | หมายเหตุ |
|--------|-------------|-------|----------|
| รายได้ก่อน VAT | VAT ตาราง 1 → `pnlIncome` / ฐานภาษี | **มี** | คีย์ยอดส่ง/ร้าน · ปิด P&L ใส่รายได้ |
| ค่าใช้จ่าย บช. พนักงาน | `ledger` → ดึงในแท็บปิด P&L | **มี** | COGS + SGA + อื่น = หักรายได้ |
| ค่าใช้จ่าย บช. เจ้าของ | `ownerBooks` → ดึงในแท็บปิด P&L | **มี** | เช่นกัน |
| กำไรประมาณการเดือน | รายได้ − ค่าใช้จ่ายสองบช. | **มี (คำนวณ)** | หลังกดดึงบช. |
| ภาษีมูลค่าเพิ่มสุทธิ | VAT ตาราง 3 | **มี** | แยกจากภาษีเงินได้บุคคล |
| ซื้อสินทรัพย์ | หมวด asset ในสองบช. | **มี (แยกแสดง)** | ไม่หักรายได้ทันที |
| ค่าลดหย่อนบุคคล (ภ.ง.ด.) | — | **ยังไม่มี** | ต้องเติมถ้าจะยื่นเงินได้ |
| ภาษีเงินได้ขั้นบันได | — | **ยังไม่มี** | คำนวณจากกำไรปี − ลดหย่อน |
| สรุปรายปี + ส่งออกยื่น | — | **ยังไม่มี** | รวม 12 เดือน / ไฟล์ยื่น |

---

## สูตรง่ายที่ใช้ได้ตอนนี้

```
รายได้เดือน (ก่อน VAT)
− ค่าใช้จ่ายดำเนินงาน บช.พนง. (COGS+SGA+อื่น)
− ค่าใช้จ่ายดำเนินงาน บช.เจ้าของ (COGS+SGA+อื่น)
= กำไรประมาณการเดือน
```

VAT สุทธิ = คนละเรื่อง (นำส่ง ภ.พ.30) — ไม่หักในสูตรเงินได้ด้านบน

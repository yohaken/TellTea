# nPos — กระดาษทุกใบ: อ่านง่าย · ไม่มีอักขระเพี้ยน

อัปเดต: **1.14.89** · vc **112** · `APP_BUILD` 509 · `POS_BUILD` 141

## แยกเอกสารให้ชัด

| เอกสาร | เมื่อไหร่ | มีตารางสรุปหมวด/รายการไหม |
|--------|----------|---------------------------|
| **ใบเสร็จลูกค้า** | หลังขาย / พิมพ์ซ้ำ | **ไม่มี** — แค่รายการบิล + ยอดสุทธิ |
| **X (Snapshot)** | กดพิมพ์ระหว่างรอบ | **มี** — สรุปรอบ ยังไม่ปิด |
| **Z (ปิดรอบ)** | ปิดกะ / ส่งเงิน | **มี** — สรุปทั้งรอบ + ส่งเงิน |

หัวกระดาษ X/Z ขึ้นชัด: `*** รายงานสรุปรอบ ***` + `(ไม่ใช่ใบเสร็จลูกค้า)`

## ทำไมมี `?` / ฟอนต์แปลก
เครื่องพิมพ์ไทยหลายตัวเข้ารหัส **TIS-620** — ตัวสวยๆ (`× • … — · −`) ไม่อยู่ในชุด → กลายเป็น `?`

แก้ทั้งระบบ:
1. แหล่งข้อความใน `ReceiptFormBuilder` / `ShiftReportFormBuilder` ใช้ ASCII
2. **ตาข่ายสุดท้าย** `ThermalSafe.ascii` ใน `EscPos.documentReceipt` — ครอบคลุมทุกใบที่พิมพ์ผ่านเส้นทางนี้

## ใบเสร็จลูกค้า (สวยขึ้น)
- เลขบิล · ชื่อร้าน · คำว่าใบเสร็จ · ยอดสุทธิ → **ตัวหนา**
- เว้นบรรทัดหัว/ท้ายรายการ · คั่นแต่ละแก้ว
- ชื่อเมนูหนา · option `- … xN` บาง (x2+ หนา)

## คนเทส
1. ขาย 1 บิล → ได้แค่ใบเสร็จสั้น **ไม่มี** ตารางหมวด/รายการท้าย
2. พิมพ์ X → หัวบอกรายงานสรุปรอบ · ไม่มี `?`
3. ปิดกะ Z → เหมือนข้อ 2 + บล็อกส่งเงิน
4. `node scripts/test-npos-thermal-all-docs.mjs`

# nPos — บิลปิดรอบ (X/Z) พิมพ์ไม่จบบน SUNMI

อัปเดต: **1.14.86** · vc **109** · `APP_BUILD` 507 · `POS_BUILD` 139

## อาการหน้างาน
- ปิดรอบแล้วกระดาษออกสั้นมาก (~หัวร้าน + เส้นคั่น + แบนเนอร์) แล้วหยุด
- ใบเสร็จขายยังพิมพ์ได้

## สาเหตุ
1. รายงาน X/Z มีหัวข้อตัวหนาหลายจุด (`BOLD` × ~10)
2. ตั้งแต่ **1.14.82** Sunmi ตัด `printText` เป็นชิ้นเล็กสลับ `ESC E` — พอคำสั่งกลางทางล้ม งานหยุดหลังแบนเนอร์
3. ปิดรอบเรียก `onDone` ก่อนพิมพ์จบ → flush/ลิ้นชักแย่งคิวปริ้น

## แก้ (1.14.84)
| ข้อ | รายละเอียด |
|-----|------------|
| เอกสารยาว | Sunmi: ถ้า bold ≥ 6 หรือยาว ≥ 1200 ตัว → พิมพ์ก้อนเดียว (ตัด marker ตัวหนา) |
| ใบเสร็จสั้น | ยังใช้ตัวหนาแบบ chunk ได้ |
| ESC E พลาด | ไม่หยุดทั้งใบ — พิมพ์ต่อ |
| ปิดรอบ | รอ callback พิมพ์จบก่อน `onDone` |
| ความกว้าง | X/Z ใช้ `PrinterPrefs.receiptCols` เท่าใบเสร็จ |

## คนเทส
1. อัป **1.14.85** → พิมพ์ X กลางรอบ → ได้ทั้งใบ (สรุปยอด / ชำระเงิน / เงินสด)
2. ปิดรอบ Z → ได้ทั้งใบ ไม่ใช่เศษสั้น
3. ขาย 1 บิล → ชื่อเมนูยังตัวหนาได้

```bash
node scripts/test-npos-z-sunmi-print.mjs
```

## P5 — ปิดเดือน (ทำต่อรอบนี้)

1. **หลัก:** แผงบน [`/pnl/`](https://telltea-shop.web.app/pnl/) — ยอดขาย/VAT → ใส่รายได้ (owner only)
2. สำรอง: แท็บ **ปิด** ใน `/vat-sales/`
3. สรุปเฉพาะวัน `confirmed` → เสนอรายได้ตามโหมดก่อน VAT / รวม VAT
4. ยืนยันมือครั้งเดียว → เขียน `monthlyIncome/{YYYY-MM}`
5. รายงาน VAT เดือนบนจอ · **ไม่** ฝัง Sp/Grab/LM ในตาราง P&L ของพนักงาน

รายละเอียดใช้งานจริง → เก็บทีหลังในตารางผลของ `vat-p5-check.md`

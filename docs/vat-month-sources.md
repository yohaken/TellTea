# ที่มายอดเดลิเวอรี่ + ยอดเดลิเวอรี่ในงบ VAT

> อัปเดต: 2026-08-01  
> **สองหน้า คนละงาน** — แหล่งที่มาพัฒนาแยก · ผสานเข้าตารางยอดเดลิเวอรี่ทันที

---

## 1) โครงหน้า

| หน้า | Route | งาน |
|------|-------|-----|
| **VAT เดือน** | `/vat-sales/` | งบสรุป · ตาราง **ยอดเดลิเวอรี่** · A/B/C/D |
| **ที่มายอดเดลิเวอรี่** | `/vat-sales/sources/` | รับยอดจากแหล่งจริง · อธิบายที่มา · ผสานเข้างบ |

```
[ที่มายอดเดลิเวอรี่]  --ผสานทันที-->  [ยอดเดลิเวอรี่ ใน VAT เดือน]
     ↑ ไฟล์/เมล/มือ                         ↑ ใช้คิดกำไร + VAT
```

- คอลัมน์「ที่มา」/ คู่มือแหล่งไฟล์ — **ถอดไว้ก่อน** (ยังไม่นิ่ง) · ใช้ช่อง **โน้ต** ส่วนตัวแทน
- หน้า VAT เดือนโชว์เฉพาะความหมายบัญชีของคอลัมน์ (ปุ่ม i)
- **ตัวเลขที่เห็นในตาราง** มาจาก Firestore `vatMonthlyReturns` (ค้างจากระบบเก่า) — ไม่ใช่จาก UI ที่ลบแล้ว  
  ล้างด้วยปุ่ม「ล้างทุกเดือน」บนหน้าที่มา หรือ workflow `purge-vat-delivery`
- **ศึกษาเมล Gmail** บนหน้าที่มา: เชื่อมครั้งเดียว · ตารางเมล · แท็กศึกษา  
  (`grab-รายวัน` / `lm-สรุปเดือน` / `excel` / `pdf` …) — จูนกับ AI ก่อน ยังไม่ผสานงบ  
  บางแอพไฟล์รายวัน · บางแอพสรุปเดือน (Excel/PDF)

---

## 2) ความหมายคอลัมน์ (หลักบัญชี — ทั้งสองหน้า)

ค่าคงที่ในโค้ด: `DELIVERY_COL_INFO` ใน `src/lib/vat-month-sources.ts`

| คอลัมน์ | ความหมาย |
|---------|----------|
| **ยอดขายแอพ** | ยอดขายที่แพลตฟอร์มรายงาน (รวม VAT) · คิดภาษีขาย |
| **ยอดโอน** | ยอดเงินเข้าบัญชีธนาคารหลังหัก GP · รายได้ถึงร้าน |
| **คชจ.GP** | ค่าบริการที่หักแวทออกแล้ว (ไม่รวม VAT) · อยู่ในโอนแล้ว ไม่หักซ้ำกำไร |
| **VAT-ซื้อ** | แวทค่าบริการขาย (ภาษีซื้อจากบิลค่า GP) · ไม่ใช่เงินหักเพิ่มจากโอน |

---

## 3) หลักการแหล่งที่มา (หน้าที่มาเท่านั้น)

ค่าคงที่: `DELIVERY_SOURCE_GUIDE`

| ช่องทาง | ต้นทาง | วิธีเข้า |
|---------|--------|---------|
| **Grab** | หลายไฟล์รายวัน | ม้วนรวม → ยอดเดือน ก่อนเข้างบ |
| **LINE MAN** | รายงานสรุปเดือน | อ่านยอดรวมตรง ๆ |
| **Shopee** | ไฟล์สรุปเดือน | อ่านยอดรวมตรง ๆ |

รายละเอียดรายวัน / ใบกำกับ / อัปโหลดอัตโนมัติ — พัฒนาต่อที่ `/vat-sales/sources/` ไม่ปนหน้า VAT

# แพทเทิร์นเงินเข้าจากเมล (VAT)

> จากเมลร้านจริง · ใช้คัดเมล → parse → ลงตารางรายวัน  
> ฐาน VAT = **ยอดลูกค้า/รายรับรวม (รวม VAT)** ÷ 1.07

## ใส่ตารางรายวัน (เงินเข้า)

| ช่อง | แพทเทิร์นหัวข้อ (ตัวอย่าง) | ยอดที่จับ | หมายเหตุ |
|------|---------------------------|-----------|----------|
| **GrabFood** | `สรุปยอดขายสำหรับคำสั่งซื้อ … GrabFood` / Daily Sales | ยอดใน **PDF แนบ** → ซิงก์ดึงข้อความ PDF ใส่ `rawText` แล้ว parse ยอดลูกค้า (Gross sales) | วันที่มักอยู่ในหัวข้อแบบ `26 กรกฎาคม 2024` |
| **LINE MAN** | `รายงานยอดขายรายวัน - LINE MAN Wongnai DD/MM/YY` | **`รายรับทั้งหมด`** (เช่น ฿ 956.00) | ปีอาจเป็น พ.ศ. สั้น `67` = 2567 |
| **ShopeeFood** | สรุปยอด / ยอดขาย ShopeeFood | ยอดสั่งซื้อสำเร็จ / ยอดลูกค้า | ตาม fixture เดิม |

## ไม่ใส่ตาราง (ข้าม)

| แพทเทิร์น | เหตุผล |
|-----------|--------|
| `Grab: Receipt/Tax Invoice No. …` | ใบกำกับรายออเดอร์ · ไม่ใช่สรุปรายวัน |
| เมลโปรโม / OTP / แจ้งเตือนทั่วไป | ไม่มียอดขายวัน |

## กฎคัดเมล (ค่าเริ่ม)

- **ต้องมีคำในหัวข้อ** แบบสรุปยอด/รายงานยอดขายรายวัน (ไม่จับแค่ from:grab.com)
- **ตัดออก:** `tax invoice` · `ใบกำกับภาษี` · `receipt/tax`
- Gmail query = `(from:…) (subject:เงินเข้า…) -subject:ใบกำกับ`

## Parse

1. วันที่จากหัวข้อ/ตัวเมล — รองรับ ค.ศ. / พ.ศ. / เดือนไทย / `DD/MM/YY`
2. ยอด gross = ป้ายเงินเข้า (LM: `รายรับทั้งหมด`)
3. Grab: ซิงก์ดึง PDF แนบ → **เก็บไฟล์** ที่ `vat-mail-pdfs/{yyyy}/{messageId}/…` + ถอดข้อความใส่ `rawText`  
   - path เก็บใน `pdfStoragePaths` · เปิดดูได้จากปุ่มในแท็บเมล (`vatMailPdfUrl`)  
   - เก็บไฟล์แม้ถอดข้อความไม่ได้ (สแกน/รหัสผ่าน) · ค่อยกรอกมือ  
4. สัปดาห์/เดือน → แท็บเทียบเท่านั้น

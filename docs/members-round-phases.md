## นโยบายที่ล็อกแล้ว

| หัวข้อ | ค่า |
|--------|-----|
| สะสม | คิดจาก **ยอดชำระจริง** = `total` หลังหักส่วนลดมือและแลกแต้ม · เรทปรับได้ที่หลังร้าน (`bahtPerPoint`) · เป้าประมาณ 3% เมื่อตั้งเรทเหมาะสม |
| บิลเล็ก | สูตร `floor(total / bahtPerPoint)` — ถ้าได้ 0 แต้มก็ได้ · **ยังพิมพ์ QR** |
| แลก | **1 แต้ม = 1 บาท** · สุทธิ **0 บาทได้** · พนักงาน**ทุกคน**ใช้ได้ |
| ลำดับเงิน | สมาชิก → ใช้แต้ม → ส่วนลดมือ → คิดเงิน → เงินสด/โอน (รับเฉพาะยอดเหลือ) |
| สลิปสมาชิก | โชว์ **ชื่อ + เบอร์** เมื่อมีสมาชิกบนบิล |
| แดชบอร์ด | บาทแลกแต้ม + **แต้มที่ได้** + **แต้มที่ตัด** |
| พักบิล | พกสมาชิก · รีเฟรชแต้มตอนดึงกลับ · เคลียร์จำนวนแต้มที่เลือกไว้ |
| **QR บนสลิป (A1)** | ดูด้านล่าง |

### QR ทุกใบ (A1) — ความหมายที่ล็อก

- พิมพ์ **QR ทุกใบ** เมื่อธงพิมพ์ QR เปิด — **ไม่ต้องมีสมาชิกก่อน**
- ใช้แต้มทั้งบิลจนสุทธิ 0 / ได้ 0 แต้มสะสม → **ยังพิมพ์ QR**
- แต้มจากสแกน QR = จาก **ยอดชำระ (`total`)** ไม่ใช่ยอดก่อนแลกแต้ม
- สแกนแล้ว:
  - ถ้าบิลยังเคลมได้และมีแต้ม > 0 → โฟลว์รับแต้ม (`/claim`)
  - ถ้าแต้มเป็น 0 หรือเคลมไปแล้ว → **ไม่ตัน** · พาไปหน้าสมาชิก (`/me` หรือสมัคร/เข้าสู่ระบบตามสถานะ)
- คำใต้ QR สั้นเชิญ เช่น «สแกนสะสมแต้ม» · ขนาดกลางท้ายบิล

เรทสะสมเริ่มต้นตอนเปิด P6 — **แนะนำ 33 บาท = 1 แต้ม (~3%)**

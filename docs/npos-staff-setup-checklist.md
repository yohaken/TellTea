# เช็คลิสต์พนักงาน — ติดตั้ง nPos จนอุปกรณ์ครบ

สำหรับส่งพนักงานหน้างาน · เฟสทดลอง  
หน้าติดตั้ง: https://telltea-pos.web.app/install/  
หลังร้านดูเครื่อง: https://telltea-shop.web.app/pos-sales/?tab=manage

## สิ่งที่ระบบทำอัตโนมัติ (ไม่ต้องกด “ตรวจสเปค”)

หลังเปิดแอป + มีเน็ต แท็บเล็ตจะ **heartbeat ~ทุก 5 วิ** ส่งกลับหลังร้าน:

| ส่งกลับ | ความหมาย |
|---------|----------|
| รุ่นเครื่อง · หน้าจอ · เวอร์ชันแอป | เห็นในตารางเครื่อง |
| สิทธิ์ (บลูทูธ / แจ้งเตือน ฯลฯ) | แถว permissions |
| จอลูกค้า (มี/ไม่มี) | สถานะจอ 2 |
| พร้อมพิมพ์หรือยัง | หลังตั้งค่าปริ้นเตอร์ในแอป |
| ออนไลน์ / เคลมแล้วหรือยัง | seat · รหัสร้าน |

ใส่ **รหัสลับ** = ขอสิทธิ์ขายบนเครื่องนี้ (ไม่ใช่ขั้นตอนวัดสเปค)  
ระบบ**ไม่บล็อก**ว่า “สเปคไม่ผ่าน” — แค่รายงานสิ่งที่เครื่องส่งมา ให้เจ้าของดูหลังร้าน

---

## A — ติดตั้งแอป (ทำคนเดียวก่อน)

- [ ] เปิดลิงก์ติดตั้งด้วย **Chrome บนแท็บเล็ต**
- [ ] ดูเลขเวอร์ชันบนหน้า → กดดาวน์โหลด → อนุญาตติดตั้งจากแหล่งนี้
- [ ] ถ้าติดตั้งทับไม่ได้: ถอน **nPos-telltea** เดิม → ดาวน์โหลดใหม่
- [ ] เปิดแอป → รอสักครู่ให้เน็ตติด (สถานะออนไลน์)
- [ ] แจ้งเจ้าของ: “เครื่องขึ้นในตารางหลังร้านแล้ว” (ยังไม่ต้องใส่รหัสก็เห็น heartbeat ได้)

## B — ใส่รหัสลับ (เมื่อเจ้าของพร้อมให้เครื่องนี้ขาย)

- [ ] ได้รหัสร้านจากเจ้าของ (รหัสเดียว · อย่าแชร์นอกทีม)
- [ ] กรอกรหัสที่หน้าเข้างาน → เคลมสำเร็จ
- [ ] ถ้าขึ้น “มีเครื่องอื่นใช้อยู่” = เครื่องอื่นถือสิทธิ์อยู่ → ให้เจ้าของ **เตะ/เคลียร์ seat** ก่อน
- [ ] หลังเคลม: แจ้งเจ้าของให้ดูตารางเครื่อง = ออนไลน์ + เคลมแล้ว

> ช่วงทดลอง: **ขายได้ทีละ 1 เครื่อง** · เครื่องจำลองถูกบล็อกขายไว้แล้ว

## C — สิทธิ์ + ตั้งค่าพื้นฐาน

- [ ] อนุญาตสิทธิ์ที่แอปขอ (บลูทูธ / แจ้งเตือน / อื่นๆ ตามเครื่อง)
- [ ] ตั้งค่า → ตรวจว่าชื่อร้าน/ที่อยู่โหลดจากหลังร้านถูกต้อง (ถ้ายังไม่ตรง รอเน็ตแล้วเปิดแอปใหม่)

## D — ปริ้นเตอร์ + ลิ้นชัก (ทำจนผ่าน)

- [ ] **SUNMI มีปริ้นในตัว:** เปิดแอปแล้วไปตั้งค่า → **พิมพ์ทดสอบ** เลย (ไม่ต้องสแกนเลือก) — ต้องอ่านไทยได้
- [ ] ปริ้นนอกเครื่อง: ต่อ USB / Bluetooth / LAN → ตั้งค่า → สแกน/เลือก → พิมพ์ทดสอบ
- [ ] กด **พิมพ์ทดสอบ** → กระดาษออก อ่านไทยได้ (ไม่เพี้ยนจีน)
- [ ] สายลิ้นชักเสียบพอร์ตเครื่องพิมพ์ (บน SUNMI มักเป็นพอร์ตหลังเครื่อง)
- [ ] ทดสอบเปิดลิ้นชัก (ปุ่มในตั้งค่า หรือจากหน้าขาย “เปิดลิ้นชัก”) → ลิ้นชักเด้ง
- [ ] แจ้งเจ้าของ: หลังร้านเห็นเครื่องพร้อมพิมพ์แล้ว (หรือส่งรูปใบทดสอบ)

## E — จอลูกค้า (ถ้ามี)

- [ ] ต่อจอ 2 / HDMI ตามที่ร้านใช้
- [ ] เปิดหน้าขาย → จอลูกค้าโชว์เมนู/ยอด (ไม่ดำ)
- [ ] แจ้งเจ้าของ: ตารางเครื่องขึ้นสถานะจอลูกค้าไม่ใช่ “—”

## F — ขายทดลองสั้น (ก่อนเปิดจริง)

ทำเมื่อ A–D ผ่าน · ใช้บิลทดลองเล็กๆ

- [ ] เข้างาน (เปิดรอบ)
- [ ] ขายเงินสด 1 บิล → ใบเสร็จออก + ลิ้นชักเปิด
- [ ] ขายโอน/พร้อมเพย์ตามที่ร้านใช้ 1 บิล → ใบเสร็จออก
- [ ] ดูหลังร้าน `/pos-sales` มีบิลขึ้น (ถามเจ้าของ)
- [ ] ออกงาน (ปิดกะ) เมื่อทดลองจบวันนั้น — หรือตามที่เจ้าของสั่ง

## G — ส่งต่อเจ้าของเมื่อ “ติดตั้งครบ”

พนักงานติ๊กครบแล้วทักกลับสั้นๆ:

```
ติดตั้งครบแล้ว
- เครื่อง: (ชื่อ/รหัส 6 ตัวท้ายจากหลังร้าน)
- ปริ้น: ผ่าน / ไม่ผ่าน · แบบ USB/BT/LAN
- ลิ้นชัก: ผ่าน / ไม่ผ่าน
- จอลูกค้า: มีผ่าน / ไม่มี
- ขายทดลอง: ผ่าน / ค้างข้อ …
```

## เจ้าของดูอะไรหลังร้าน (ไม่ต้องยืนข้างเครื่อง)

`/pos-sales` → แท็บ **จัดการ**

| ดูที่ | ผ่านเมื่อ |
|-------|----------|
| ตารางเครื่อง | ออนไลน์ · เวอร์ชันตรง · เคลม/seat |
| สิทธิ์ | ไม่แดง / ไม่ขาดสิทธิ์สำคัญ |
| จอลูกค้า | สถานะไม่ใช่ unknown ค้างนานหลังต่อจอ |
| ตรวจเครื่อง (diagnose) | ถ้าอยากดูรายละเอียดจอ/USB — สั่งจากเครื่องหรือรอออโต้ |

## อย่าทำช่วงทดลอง

- อย่าปิดติ๊ก **ปิดกั้นเครื่องจำลอง** ถ้ายังไม่ต้องการยอดทดสอบปนยอดจริง
- อย่าให้ 2 เครื่องเคลมพร้อมกันโดยไม่เตะเครื่องเดิม
- อย่าถอนแอปกลางกะโดยไม่ปิดรอบ (ถามเจ้าของก่อน)

# nPos — พนักงานดูบิลย้อนหลังได้อะไร (มาตรฐานเคาน์เตอร์)

อัปเดต: **1.14.39**

## วิเคราะห์สั้น

พนักงานเปิดประวัติใบเสร็จบนเครื่องเพื่อ **ความมั่นใจ + แก้ปัญหาหน้างาน** ไม่ใช่เพื่อแก้เมนู/ตั้งค่าร้าน

| ทำได้ | ทำไม | มาตรฐาน |
|--------|------|----------|
| **ดูรายการ + ยอด + ชำระ** | ตรวจเงินในลิ้นชัก / โต้แย้งลูกค้า | ✅ มี |
| **พิมพ์ซ้ำ** | ปริ้นเตอร์พัง · หมึกไม่ชัด · ใบหาย · ลูกค้าขอสำเนา | ✅ มี |
| **ทำลายบิล (void)** | คิดผิด · ลูกค้ายกเลิกหลังพิมพ์ · ตัดยอดรอบ | ✅ มี (เหตุผลแนะนำ) |
| แก้รายการในบิลเก่า | เสี่ยงทุจริต · ยอดเพี้ยน | ❌ ไม่ทำ — ทำลายแล้วขายใหม่ |
| ปิด/เปิดกะย้อนหลัง | บัญชีวันเพี้ยน | ❌ ไม่ทำจากประวัติบิล |
| ดูบิลเครื่องอื่น | seat คนละเครื่อง | ❌ แค่ใบบนเครื่องนี้ (local) |

## นโยบายที่ล็อก

1. **พิมพ์ซ้ำได้เสมอ** ถ้าบิลยังไม่ทำลาย — ไม่ต้องขอรหัสเจ้าของ  
2. **ทำลายบิล** ตัดยอดรอบ + ซิงก์ขึ้นเซิร์ฟเมื่อมีเน็ต · แนะนำใส่เหตุผล  
3. **บิลทำลายแล้ว** ดูได้เพื่อตรวจ · พิมพ์ซ้ำไม่ได้  
4. **หลังบ้าน** void ได้เฉพาะบิลวันนี้ (รายงาน) · ไม่พิมพ์จาก BO  

## UI ที่ชัดขึ้น (1.14.39)

ข้อความหน้าประวัติบอกชัด: ตรวจยอด · พิมพ์ซ้ำเมื่อใบมีปัญหา · ทำลายเมื่อผิด

# nPos — ใบเสร็จอ่านง่าย (ASCII qty · เว้นบรรทัด · ชื่อตัวหนา)

อัปเดต: **1.14.95** · `versionCode` 118 · `APP_BUILD` 535 · `POS_BUILD` 149

## ปัญหาที่แก้
- พิมพ์ `×2` → เครื่อง TIS-620 โชว์ **`?2`**
- รายการติดกัน อ่านยาก
- ชื่อเมนูกับ option น้ำหนักเท่ากัน
- ท็อปปิ้งไม่บอกจำนวน

## ฟอร์มใหม่ (กระดาษ + ข้อความพาริตี้)
| | ก่อน | หลัง |
|--|------|------|
| qty รายการ | `×2 ชื่อ` (หรือไม่โชว์เมื่อ =1) | **คอลัมน์ 2 ตัวอักษร** ` 1` / `12` + ชื่อ (ASCII) |
| option | `• หวาน 50%` · ไม่โชว์ ×1 | **เยื้อง 4 ช่อง** `- หวาน 50%` (ไม่มี x1) |
| x2+ option | `×n` เมื่อ >1 | `- หวาน 50% x2` **ตัวหนา** (ESC E / web `.mod-qty--hot`) |
| ชื่อรายการ | น้ำหนักเท่า option | **ตัวหนา** (ESC E / `.name`) — รวม path **SUNMI InnerPrinter** (1.14.82) |
| ระหว่างรายการ | ติดกัน | **เว้นบรรทัดว่าง 1 บรรทัด** |

## คนเทส
1. ขาย 2 แก้วเดียวกัน → กระดาษขึ้น ` 2 …` **ไม่มี `?`** · ราคาเรียงแนวตั้ง
2. ท็อปปิ้ง 2 หน่วย → โชว์ `    - … x2` (เยื้อง) · x2 ตัวหนา
3. หลายรายการ → มีช่องว่างคั่นชัด
4. ชื่อเมนูเข้ม · บรรทัด option บาง (ยกเว้น x2+) — ทดสอบบน **SUNMI** ด้วย

# nPos — ใบเสร็จอ่านง่าย (ASCII qty · เว้นบรรทัด · ชื่อตัวหนา)

อัปเดต: **1.14.81** · `versionCode` 104 · `APP_BUILD` 408 · `POS_BUILD` 133

## ปัญหาที่แก้
- พิมพ์ `×2` → เครื่อง TIS-620 โชว์ **`?2`**
- รายการติดกัน อ่านยาก
- ชื่อเมนูกับ option น้ำหนักเท่ากัน
- ท็อปปิ้งไม่บอกจำนวน

## ฟอร์มใหม่ (กระดาษ + ข้อความพาริตี้)
| | ก่อน | หลัง |
|--|------|------|
| qty รายการ | `×2 ชื่อ` (หรือไม่โชว์เมื่อ =1) | **`2 ชื่อ`** เสมอ (ASCII) |
| option | `• หวาน 50%` · `×n` เมื่อ >1 | **`- หวาน 50% x1`** เสมอ |
| x2+ option | ตัวอักษรพิเศษ | **ตัวหนา** (ESC E / web `.mod-qty--hot`) |
| ชื่อรายการ | น้ำหนักเท่า option | **ตัวหนา** (ESC E / `.name`) |
| ระหว่างรายการ | ติดกัน | **เว้นบรรทัดว่าง 1 บรรทัด** |

## คนเทส
1. ขาย 2 แก้วเดียวกัน → กระดาษขึ้น `2 …` **ไม่มี `?`**
2. ท็อปปิ้ง 2 หน่วย → โชว์ `x2` ตัวหนา
3. หลายรายการ → มีช่องว่างคั่นชัด
4. ชื่อเมนูเข้ม · บรรทัด option บาง (ยกเว้น x2+)

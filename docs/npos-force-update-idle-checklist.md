# nPos — บังคับอัปเดตเมื่อว่าง (+ สิทธิ์ติดตั้ง + เสียง)

อัปเดต: **1.14.98** · `versionCode` 121 · `APP_BUILD` 538 · `POS_BUILD` 152

## มติเจ้าของ
| พฤติกรรม | รายละเอียด |
|----------|------------|
| มี APK ใหม่ | **บังคับติดตั้งเสมอ** — ไม่มี Later / snooze |
| กำลังขาย (ตะกร้ามีของ) | **ยังไม่ติดตั้ง** · ไม่โชว์ป๊อปบังคับทับจอคิดเงิน |
| ตะกร้าว่าง | โชว์ป๊อปบังคับ + เสียง「กรุณาอัปเดตโปรแกรม」ทุก ~3 วิ + เริ่มดาวน์โหลด/ติดตั้งเอง |
| สิทธิ์ติดตั้ง | ถ้ายังไม่ได้อนุญาต unknown sources → เปิดหน้าตั้งค่า · เตือนซ้ำจนกว่าจะเปิด · แล้วติดตั้งต่อ |

## ไฟล์หลัก
- `UpdatePromptController` · `UpdateBusyGate` · `UpdateNagVoice`
- `SellActivity` (busy = cart not empty)
- `ApkInstaller.canInstallPackages` / `REQUEST_INSTALL_PACKAGES`

## คนเทสเคาน์เตอร์
1. ปล่อย APK ใหม่ → ตอนตะกร้าว่าง ต้องเด้งป๊อป + ได้ยินเสียงเตือน
2. ใส่ของในตะกร้า → ป๊อปหาย · ไม่ติดตั้งค้างระหว่างคิดเงิน
3. เก็บเงินจนตะกร้าว่าง → ป๊อปกลับมา + ติดตั้งต่อ
4. เครื่องที่ยังไม่เปิดสิทธิ์ติดตั้ง → เด้งหน้าตั้งค่า · เปิดแล้วอัปต่อเอง

```bash
node scripts/test-npos-force-update-pulse.mjs
```

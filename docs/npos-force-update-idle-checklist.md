# nPos — บังคับอัปเดตทันที (+ สิทธิ์ติดตั้ง + เสียง)

อัปเดต: **1.14.101** · `versionCode` 124 · `APP_BUILD` 543 · `POS_BUILD` 155

## มติเจ้าของ
| พฤติกรรม | รายละเอียด |
|----------|------------|
| มี APK ใหม่ | **บังคับติดตั้งทันที** — ไม่มี Later / snooze |
| UI | ป๊อป**กลางจอ** · การ์ดกะทัดรัด · ปุ่มเดียว「อัปเดต」· บังหน้าจอด้านหลัง |
| กำลังขาย / ตะกร้ามีของ | **ไม่รอ** — โชว์ป๊อป + ติดตั้งต่อทันที (บันทึกตะกร้าก่อนติดตั้ง) |
| สิทธิ์ติดตั้ง | ถ้ายังไม่ได้อนุญาต unknown sources → เปิดหน้าตั้งค่า · เตือนซ้ำจนกว่าจะเปิด · แล้วติดตั้งต่อ |
| เสียง | 「กรุณาอัปเดตโปรแกรม」ทุก ~3 วิ จนกว่าจะติดตั้ง |

## ไฟล์หลัก
- `include_update_popup.xml` · `UpdatePromptController` · `UpdateNagVoice`
- `SellActivity` (`setBeforeInstall` เก็บงานก่อนรีสตาร์ท)
- `ApkInstaller.canInstallPackages` / `REQUEST_INSTALL_PACKAGES`

## คนเทสเคาน์เตอร์
1. ปล่อย APK ใหม่ → ป๊อปกลางจอ + ปุ่ม「อัปเดต」อย่างเดียว + เสียงเตือน
2. แตะรอบนอกป๊อปแล้วทำงานอื่นต่อไม่ได้
3. หลังติดตั้ง → กลับหน้าขาย · ตะกร้าที่บันทึกไว้ยังอยู่

```bash
node scripts/test-npos-force-update-pulse.mjs
```

# nPos — เอกสารร้าน + ลิ้นชัก + ติดตั้งฮาร์ดแวร์

อัปเดต: **1.14.25** · `APP_BUILD` 279 · `POS_BUILD` 78 · `versionCode` 48  

เป้าหมาย: เอกสาร (ใบเสร็จ / X / Z) เป็น family เดียวกัน · ใช้**ข้อมูลร้าน**ไม่ใช่แบรนด์ระบบ · ลิ้นชักมี policy ชัด · ติดตั้งฮาร์ดแล้วเทสจบ

---

## A — เอกสารร้าน (shop-first)

### หลักร่วม
| ชิ้น | ใช้ข้อมูลร้าน | ไม่ใช้ |
|------|----------------|--------|
| Header | shopName · shopNameTh · address · phone | TellTea / nPos บนลูกค้า |
| Footer | receiptFooterNote ของร้าน | `TellTea POS` |
| Meta | เวลา · บิล · พนักงาน · รหัสเครื่อง · รอบ | แบรนด์ผลิตภัณฑ์ |

### หน้าที่คนละแบบ · โครงเดียวกัน
| เอกสาร | หน้าที่ | ลิ้นชัก |
|--------|---------|---------|
| **ใบเสร็จ** | หลักฐาน transaction | เปิดหลังขายสดเท่านั้น |
| **X snapshot** | สรุประหว่างรอบ · ไม่ปิดรอบ | ไม่เปิด |
| **Z close** | ปิดรอบ · นับลิ้นชัก · เซ็น | ไม่เปิด |

### ตรวจโค้ด
- `ReceiptFormBuilder` / `receipt-template` / `receipt-text-form` — ไม่มี `TellTea POS`
- `EscPos.documentReceipt` — ไม่ inject แบรนด์; `saleReceipt` = alias
- `EscPos.testReceipt` — หน้าทดสอบติดตั้งเท่านั้น (PRINTER TEST)

## B — Policy ลิ้นชัก (`CashDrawerPolicy`)

ลิ้นชักพ่วง **พอร์ตเครื่องพิมพ์** ที่เลือกไว้ (ไม่ใช่อุปกรณ์แยกในแอป)

| สถานการณ์ | เปิดลิ้นชัก? |
|-----------|----------------|
| ขายเงินสด + พิมพ์สำเร็จ | ✅ |
| PromptPay | ❌ |
| พิมพ์ใบเสร็จซ้ำ | ❌ |
| X / Z report | ❌ |
| เปิด/ปิดกะอย่างเดียว | ❌ |
| Settings → ทดสอบลิ้นชัก | ✅ (manual) |

## C — Checklist ติดตั้งฮาร์ดหน้างาน

ชุดมาตรฐาน 1 เคาน์เตอร์:
1 tablet · 1 ESC/POS printer · 1 drawer พ่วง printer · (จอลูกค้าถ้ามี)

### ติดตั้ง
- [ ] เสียบ/จับคู่ printer (USB / BT / LAN)
- [ ] Settings → สแกน → เลือก endpoint → **พิมพ์ทดสอบ** ผ่าน
- [ ] สายลิ้นชักเข้าพอร์ต printer → **ทดสอบเปิดลิ้นชัก** ผ่าน
- [ ] ตั้งชื่อ/ที่อยู่ร้านจากหลังบ้าน → รีโหลดแอป → หัวบิลตรง
- [ ] เคลมเครื่องด้วยรหัสร้าน (ถ้าเกตเปิด)

### Acceptance
- [ ] ขายสด → ใบเสร็จออก + ลิ้นชักเปิด
- [ ] PromptPay → ใบเสร็จออก · ลิ้นชัก**ไม่**เปิด
- [ ] พิมพ์ซ้ำจากประวัติ → กระดาษอย่างเดียว · ลิ้นชักไม่เปิด
- [ ] พิมพ์ X / ปิดกะ Z → รายงานออก · ลิ้นชักไม่เปิด
- [ ] ท้ายใบเสร็จเป็นข้อความร้าน · **ไม่มี** TellTea POS

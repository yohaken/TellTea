# ทางลัดเจ้าของ (Owner Quick Dock)

> ชิปตัวย่อลอยเหนือเมนูล่าง · เจ้าของเท่านั้น · ทุกหน้าหลังร้าน · build 633+

## ทำไมแนวนี้เหมาะสม

| ข้อ | เหตุผล |
|-----|--------|
| แยกจากแถบล่าง | แถบล่าง = งานพนักงานรายวัน · ทางลัดนี้ = หน้าเจ้าของ/หมวดที่ใช้บ่อย |
| ตัวย่อ ไม่ใช้ไอคอนใหญ่ | แตะง่าย · อ่านเร็ว · ตั้งชื่อย่อเองได้ |
| โมเดลแยก (`ownerQuickKeys`) | จัดลำดับเองได้โดยไม่กระทบ `dockTabKeys` ของทั้งร้าน |
| ตั้งค่าในโมดูล + กดค้าง | อื่นๆ → ตั้งค่าโมดูล → ไอคอนลอย · หรือกดค้างชิปบนหน้างาน |
| เฉพาะเจ้าของ | พนักงานไม่เห็น / ไม่รก |

## UX เลย์เอาต์ (เหนือเมนูล่าง)

```
[ + กรอก เล็ก ]     [ เจ ][ VAT ][ กำไร ][ พนง ] →
   ซ้ายสุด              กลาง ──────────────→ ขวา
```

- ปุ่มพนักงาน `+ กรอก` (ModuleTabDock): **ซ้ายสุด**
- ทางลัดเจ้าของ: เรียง **จากกลางไปขวา**
- แตะสั้น → ไปหน้า · กดค้าง → ตั้งค่า (สูงสุด 10)
- ค่าเริ่มต้น: **เจ · VAT · กำไร · พนง**

## ตั้งค่าโมดูล

อื่นๆ → ตั้งค่าโมดูล → **ไอคอนลอย (ทางลัดเจ้าของ)**

- ปิด/เปิดทุกหมวด (บัญชี · ผลิต · ชง · จ่าย · เช็ค · คลัง · งาน · บช.เจ้าของ · VAT · ทุน · สรุปรายเดือน · พนง · เมนู · POS · โนต · ยูทิลิตี้ · ส่งออก · ตั้งค่า · โปรไฟล์ · อื่นๆ)
- เรียงลำดับ ↑↓
- ตั้งชื่อย่อ (สูงสุด 4 ตัว) — บันทึกทันที

## เก็บข้อมูล

`meta/ui` (owner write · merge กับ nav UI เดิม)

| ฟิลด์ | ความหมาย |
|-------|----------|
| `ownerQuickKeys: string[]` | ลำดับชิปที่เปิด |
| `ownerQuickAbbrs: { [key]: string }` | ชื่อย่อที่แก้จากค่าเริ่ม (เก็บเฉพาะที่ต่าง) |

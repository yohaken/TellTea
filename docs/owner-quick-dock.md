# ทางลัดเจ้าของ (Owner Quick Dock)

> ชิปตัวย่อลอยเหนือเมนูล่าง · เจ้าของเท่านั้น · build 400

## ทำไมแนวนี้เหมาะสม

| ข้อ | เหตุผล |
|-----|--------|
| แยกจากแถบล่าง | แถบล่าง = งานพนักงานรายวัน · ทางลัดนี้ = หน้าเจ้าของที่อยู่ใต้ «อื่นๆ» |
| ตัวย่อ ไม่ใช้ไอคอนใหญ่ | แตะง่าย · อ่านเร็ว |
| โมเดลแยก (`ownerQuickKeys`) | จัดลำดับเองได้โดยไม่กระทบ `dockTabKeys` ของทั้งร้าน |
| กดค้างตั้งค่า | ไม่ต้องเข้า Settings · ปรับหน้างานได้ทันที |
| เฉพาะเจ้าของ | พนักงานไม่เห็น / ไม่รก |

## UX เลย์เอาต์ (เหนือเมนูล่าง)

```
[ + กรอก เล็ก ]     [ เจ ][ VAT ][ กำไร ][ พนง ] →
   ซ้ายสุด              กลาง ──────────────→ ขวา
```

- ปุ่มพนักงาน `+ กรอก` (ModuleTabDock): **ซ้ายสุด** · เล็กลง ~ครึ่ง ยังแตะได้
- ทางลัดเจ้าของ: เรียง **จากกลางไปขวา** แถวเดียวกับปุ่มพนักงาน — ไม่ทับกัน
- แตะสั้น → ไปหน้า · กดค้าง → ตั้งค่าลำดับ (สูงสุด 6)
- ในตั้งค่า: รายการที่เปิดเรียงตามลำดับจริง · ↑↓ เลื่อนแถวทันที (แล้วบันทึก Firestore)
- ปุ่ม `+ กรอก` / `+ ออก` ซ้ายถูกจำกัดความกว้าง — ไม่บังชิปเจ้าของ
- ค่าเริ่มต้น: **เจ · VAT · กำไร · พนง**

## เก็บข้อมูล

`meta/ui.ownerQuickKeys: string[]` (owner write · merge กับ nav UI เดิม)

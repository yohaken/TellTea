1. ลิ้นชักรอพิมพ์+ตัดกระดาษจบก่อนถึงค่อยเตะ
2. Sunmi ใบเสร็จสั้นใช้ bold ทีละชิ้น (AIDL หลายรอบ)
3. `flushOne` HTTP บนเธรดเดียวกับบันทึกบิล → บิลถัดไปรอเน็ต

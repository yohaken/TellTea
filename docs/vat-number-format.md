# มาตรฐานรูปแบบตัวเลข (VAT / เงินในร้าน)

> บังคับใช้ทุกหน้าที่มีเงิน · โดยเฉพาะ `/vat-sales/`  
> โค้ด: `src/lib/vat-number-format.ts`  
> อัปเดต 2026-07-29

**กฎหลัก:** ตัวเลขเงิน — ไม่ว่าคนกรอกเองหรือระบบเจน/ดึงมา — **ต้องมีคอมม่าหลักพันเสมอ** และทศนิยม 2 ตำแหน่ง  
ตัวอย่างถูก: `12,345.67` · `7.00` · `0.00`  
ตัวอย่างผิด: `12345.67` · `12345` · `12,345.6`

เมื่อสร้างระบบใหม่ หรืออัปเดตหน้าที่มียอดเงิน **ต้องปรับให้เข้ามาตรฐานนี้** อย่าใช้ `String(n)` / `toFixed(2)` เปล่าๆ ใน UI

---

## แยกชนิดให้ชัด

| ชนิด | ทศนิยม | คอมม่า | ตัวอย่างแสดง | ใช้กับ | ฟังก์ชัน |
|------|--------|--------|-------------|--------|----------|
| **เงิน (บาท)** | **2** | **เสมอ** | `12,345.67` | ยอดขาย · ภาษี · GP · P&L · ช่องกรอกเงิน · ค่าที่ระบบเติม | `formatVatMoney` / `moneyFieldValue` |
| **เปอร์เซ็นต์** | **2** | เมื่อถึงหลักพัน | `7.00%` · `90.00%` | เรทขาย · นำส่ง% · GP% | `formatVatPct` / `pctFieldValue` |
| **จำนวนเต็ม** | **0** | เมื่อถึงหลักพัน | `31` · `1,200` | นับวัน · ชิ้น | `formatVatInt` |

---

## กฎบังคับ

1. **แสดงในตาราง / สรุป / ข้อความ** → `formatVatMoney` (มีคอมม่า + `.00`)
2. **ช่องกรอกเงิน** → ค่าที่ระบบใส่ใช้ `moneyFieldValue` (รูปแบบเดียวกับแสดงผล) · ตอน blur ใช้ `normalizeMoneyFieldText`
3. **parse ก่อนคำนวณ** → `parseVatMoneyInput` (ตัดคอมม่าก่อน `Number`)
4. **ห้าม** `toFixed(2)` / `formatPlainNumber` ใหม่ใน UI เงิน — ให้ใช้ชุดนี้
5. **ห้าม** `type="number"` สำหรับช่องเงินที่ต้องเห็นคอมม่า (ใช้ `inputMode="decimal"` + ข้อความ)
6. **ห้าม** ปนชนิด (อย่าแสดงเรทขายเป็นบาท หรือยอดเงินเป็น %)

---

## ช่องกรอก vs ค่าคำนวณ

| จุด | ถูก | ผิด |
|-----|-----|-----|
| ระบบดึงภาษีซื้อใส่ช่อง | `1,234.56` | `1234.56` |
| คนพิมพ์แล้วออกจากช่อง | format เป็น `1,234.56` | ค้าง `1234.56` |
| แถวสรุปที่คำนวณให้ | `formatVatMoney(n)` | `n.toFixed(2)` |
| confirm / toast | `formatVatMoney(n)` | `formatPlainNumber` (เลิกใช้ในหน้าใหม่) |

แยกช่องทาง (Shopee / Grab / LINE MAN / หน้าร้าน) — ดู [`pnl-gp-by-channel.md`](./pnl-gp-by-channel.md)

| **เรท %** | หักเป็น % ของรายได้ช่องนั้น | `รายได้ช่องทาง × เรท% ÷ 100` |
| **ยอดบาท** | ใส่ยอดหัก fix | ใช้ยอดที่คีย์ (แสดงมีคอมม่า) |

## Checklist ตอนสร้าง/อัปเดตระบบ

- [ ] แสดงเงินใช้ `formatVatMoney` ไม่ใช่ `toFixed` / `String(n)`
- [ ] ช่องกรอกเงินเติมด้วย `moneyFieldValue` · blur ด้วย `normalizeMoneyFieldText`
- [ ] คำนวณจากช่องด้วย `parseVatMoneyInput`
- [ ] ทดสอบด้วยยอด ≥ 1,000 ว่าเห็นคอมม่าทั้งตอนเจนและตอนพิมพ์
- [ ] อัปเดตเอกสารหน้างานให้ชี้มาที่ไฟล์นี้ถ้ามีตัวเลขเงิน

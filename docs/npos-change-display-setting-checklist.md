# nPos — แสดงเงินทอน (ค้าง · ✕ · ทอนล่าสุด)

อัปเดต: **1.14.95** · `APP_BUILD` 534 · `POS_BUILD` 149 · vc **118**

## เป้า (มาตรฐานเคาน์เตอร์)
- ค้างยอดทอนชัดเจนหลังรับสด (ค่าเริ่ม **10 วิ**)
- ปิดได้ทันที: กด **✕** หรือ **แตะที่อื่น** บนหน้าขาย
- หลังปิดแล้วยังเห็น **«ทอนล่าสุด ฿…»** จนกว่าจะเริ่มบิลใหม่ — กันลืมตอนส่งเงิน
- ตั้งเวลาได้โดยไม่ต้องหาเมนูตั้งค่าลึก

## ที่ตั้งค่า
| ทาง | วิธี |
|-----|------|
| ทางลัด | หน้าขาย → เมนู **▦** → **เวลาแสดงเงินทอน · …** (แตะเพื่อวนค่า) |
| เต็ม | ตั้งค่าเครื่อง → การชำระเงิน → ระยะเวลาแสดงหน้าต่างเงินทอน → เปลี่ยนค่า |

ค่าที่วนได้: `3 · 5 · 8 · 10 · 12 · 15` วินาที · **ปิดด้วยตนเอง (กด ✕)**  
ค่าเริ่มต้น: **10 วินาที** (เครื่องนี้เท่านั้น · ไม่ซิงก์ BO)

## พฤติกรรม
| | จอขาย | จอลูกค้า |
|--|--------|----------|
| หลังทอน | แถบเขียว + นับถอยหลัง + ✕ | ค้างเงินทอนตามเวลา |
| แตะที่อื่น / ✕ | ปิดแถบทันที | ไปรีวิวบิล |
| หลังปิดแถบ | สถานะ **ทอนล่าสุด ฿…** ค้าง | — |
| เริ่มบิลใหม่ | ล้างทอนล่าสุด | หน้าเลือกเมนู |

## คนเทส
1. จ่ายสดทอน → แถบเขียวขึ้น · เห็นนับถอยหลัง · กด ✕ ปิดได้
2. จ่ายสดทอน → แตะเมนู/ตะกร้า → แถบหาย · เหลือ «ทอนล่าสุด»
3. ▦ → เวลาแสดงเงินทอน → เปลี่ยนเป็น 5 วิ / ปิดด้วยตนเอง
4. เริ่มบิลใหม่ → «ทอนล่าสุด» หาย

# P6 — เกตเปิดใช้สมาชิกหน้าร้าน

อัปเดต: 2026-08-07  
อิง: [members-round-phases.md](./members-round-phases.md) · [members-staff-guide.md](./members-staff-guide.md) · [members-redeem-checklist.md](./members-redeem-checklist.md) §D5 / §8 / §21

**อย่าเปิดธงบนเครื่องขายจริงจนกว่าแมทริกซ์ด้านล่างผ่านบนเครื่องเทส**

---

## สถานะโค้ดก่อนเกต

| ชิ้น | สถานะ |
|------|--------|
| P0–P3 เซิร์ฟเวอร์ / หลังร้าน / แดชบอร์ด | ✅ |
| P4 nPos สมาชิก+ใช้แต้ม (APK ≥ 138) | ✅ |
| P5 สลิป + QR ทุกใบเมื่อธงเปิด (APK ≥ 139) | ✅ |
| คอนเฟิร์มแต้มหลังใส่เบอร์ (APK ≥ 140) | ✅ |
| ธงค่าเริ่ม | `enabled` ปิด · `receiptClaimEnabled` ปิด |

---

## ลำดับเปิดธง (เจ้าของ)

1. อัป nPos เครื่องเทสเป็น **APK 140+**
2. ตั้งเรทสะสม (แนะนำเริ่ม **33 บาท = 1 แต้ม ≈ 3%** เมื่อแลก 1:1) · แลกคง **1 แต้ม = 1 บาท**
3. ให้พนักงานอ่าน [คู่มือ 1 หน้า](./members-staff-guide.md)
4. ทำแมทริกซ์เทสด้านล่างบนเครื่องเทส
5. เมื่อผ่าน → หลังร้าน `/members` → ตั้งค่า:
   - เปิด **ระบบสมาชิก**
   - (แยกตัดสินใจ) เปิด **ทดลอง QR สลิป** เมื่อพร้อมพิมพ์ QR ทุกใบ
6. ชั่วโมงแรก: ขายปกติ 2–3 บิล → แลก 1 บิล → เช็คแดชบอร์ด + สลิป + แต้มสมาชิกทดลอง
7. ปิดกะวันนั้น — เงินสดต้องตรง

---

---

## แผนปิดธงฉุกเฉิน

ถ้าเพี้ยนยอด / พนักงานสับสน / แต้มผิด:

1. หลังร้าน → `/members` → ตั้งค่า → **ปิดระบบสมาชิก** → บันทึก  
   - เครื่องรีเฟรชตั้งค่าแล้วปุ่มสมาชิกหาย · ขายปกติต่อได้ทันที
2. ถ้าปัญหาอยู่ที่ QR อย่างเดียว → ปิดแค่ **ทดลอง QR สลิป** (ขาย+แลกยังใช้ได้)
3. อย่ารีบ void ยกแผง — จดเลขบิล · เบอร์ · เวลา · เครื่อง แล้วค่อยแก้แต้มมือถ้าจำเป็น
4. บิลที่แลกไปแล้วยังอยู่ใน Firestore — การปิดธงไม่ลบบิลเก่า
